## 2026-11-16 渠道设置反馈修复（#1139）

- 模型映射的产品起点是**当前 Key 分组能用的前端模型**：先按当前分组真实模型的分类筛前端模型，再在行内选择真实模型。不要改回“平铺整份全局前端模型目录”，否则用户会看到当前分组根本无法映射的行。
- “不常用”是全局前端模型开关，但必须在当前映射表即时体现：默认隐藏该行，映射数据保留；“显示不常用模型”负责恢复查看。按钮切换不是只改文字，必须让该行消失。
- API Key 行是四个独立几何：输入框（眼睛绝对定位在框内）、保存按钮、官网入口。输入 wrapper 不能吃掉右侧按钮；`tokenInput` 必须 `width:100%`、`box-sizing:border-box`、`padding-right` 给眼睛留位。
- RunningHub 的工作流入口由协议严格判定 `selected.protocol === 'runninghub-api'`，不能按渠道是否“看起来像 RunningHub”或对所有渠道显示。
- 设置页交互态继续走全局令牌：hover 用 `--bg-hover`，控件圆角用 `--radius-control`，胶囊才用 `--radius-pill`；不要引入局部 4/5/6/8/999px 或未定义 `--warning`。
- 验收口径：1440×900 / 1024×700 × 明暗四组，几何断言输入框/眼睛/保存/官网互不覆盖、可见方按钮圆角一致、无横向溢出、pageerror 0；证据见 `review/2026-11-16-channel-settings-feedback/after-v2/`。
- 长驻 Vite 进程热更新后可能残留同一 CSS Module 的旧哈希，导致 `:hover` 规则引用旧 `.item`，表现为拖拽手柄/三点按钮不出现。冒烟前先起全新 Vite 进程；本轮 g8/g44/g45/g74 四组 97/97 通过。
- 2026-11-16 #1140：模型映射按 `生图 / 对话 / 视频 / 配音` 分组；右侧常用状态用真正的 `role="switch"`，开=常用、关=不常用，关闭后默认隐藏、映射保留。分类与开关样式独立到 `SettingsModelCategory.module.css`，避免抬高映射主模块预算。

## 2026-11-17 Key 分组改文件夹标签（#1144 二轮）

- 用户要「选中态就是一个梯形、其他标题没有背景、点别的标题滑过去」。正确做法是**标题栏里放一块浮动指示器**（`position:absolute` + `transform: translateX` + `width` 过渡），位置和宽度从真实 DOM 量（`getBoundingClientRect` 差值 + `scrollLeft`，`ResizeObserver` 与 `document.fonts.ready` 后重测）；**不要**给每个标题各画一块背景再靠宽高动画对齐——切换时两块形状会同时缩放，看起来是「两个标签在打架」。
- 标题字重必须全组一致（用 `--fw-title` 给所有标题）。选中态加粗会改变文字宽度，切换瞬间整条标题栏抖动；选中与未选中只靠颜色（`--text-1` / `--text-2`）和那块梯形区分。
- 标题里不能再塞状态点 / 编辑 / 删除按钮：双击选中标题改名、右键标题出「编辑 / 删除」菜单（复用 `channelContextMenu` / `channelMenuItem` 那套样式）。删除仍走 `removeKeyGroup`，给它加可选 `{ groupId, skipConfirm }`，菜单内二次确认后按 id 精确删，只剩一组时禁用。
- 重命名输入框要「跟着文字走且不能太长」：用镜像 `<span aria-hidden>` 撑宽度、输入框 `position:absolute; inset:0`，外层 `max-width:160px`。别用 `size` 或固定 px——中文宽度估不准。
- **Esc 必须 `stopPropagation()`**：`GlobalSettingsOverlay` 在 window 上监听 Esc 直接关整个设置浮层；菜单只 `preventDefault()` 的话，按一次 Esc 连设置页一起关掉（本轮实测踩到）。
- 双击**未选中**的标题会先切组再进编辑，而「activeGroup 变了就重置改名/优先级/菜单」的 effect 会把刚打开的输入框关掉。用 `renameTargetRef` 标记「这次切组是我自己触发」来豁免一次。
- 门禁教训：#1144 首轮按用户要求「暂不跑测试」，直接提交后留下 8 处模块治理违规（3 个文件超预算、2 个新文件未登记、1 个已删文件仍在登记、1 个已删 CSS 类还在 publicApi）、1 处 `lucide-react` 直引 eslint、`data-settings-card` 出现 3 处导致唯一性门禁失败、g44/g74 共 4 条断言过期。**改动可以按用户要求只做目视，但提交前 `npm run check` + 相关冒烟必须绿**，否则下一轮要先替上一轮还债。

## 2026-11-17 Key 分组改圆润文件夹标签（#1144 三轮）

- 用户第二轮否掉了斜切梯形：「形状我要这种圆角的」，并要求**选中的分组自动排第一列**、修「加号和文字不在同一排」。叠加起来最省事的结构是：渲染时把当前分组提到数组首位 → 选中标签永远贴左边 → 卡片左上角直角、只需在**右下角**画一条内凹圆弧，不必为「标签在中间」补左右两半。
- 参考图（用户第一张截图）真正的几何：选中标签 55px、未选中 ~37px，**选中要「立起来」一档**，两条竖边之间留 16px 窄缺口、缺口底部各有一段内凹圆弧；未选中标签底色几乎等于卡片色（实测 #202020 vs 卡片 #1f1f1f）。只做等高圆角卡片一定不像，高度差 + 缺口才是关键。
- 高度不一致时加号不能贴任何一边：取两者文字中心的中点（选中 28 / 未选中 20 → 24），34px 加号 `margin-bottom: 7px`，与两边各差 4px。
- 未选中标签底色不能靠 `color-mix(--bg-subtle, --bg-canvas)`：浅色主题页面比卡片**更亮**、深色相反，一条相对关系会在浅色下算出比卡片还浅、几乎看不见的底。按主题各给一值（新增 `--bg-tab-idle`：浅 #f2f2f2 / 深 #1e1e1e，只比卡片深一小档），令牌仍集中在 `tokens.css`。
- 内凹圆弧：小方块 + `radial-gradient(circle at 0 100%, transparent 10px, 卡片色 10.5px)`，盒子左下角必须落在「标签右切线与卡片顶边」的交点；标签间距要 ≥ 圆弧宽度（10px），否则下一枚标签会盖住弧。
- 选中态背景用独立层（`width` 过渡）而不是给标签自己上色：标签宽度随文字变，`background` 没有过渡，独立层的 `width` 有。
- 冒烟里给这套造型钉了 4 条：选中排第一 / 52px 与选中块等宽、12px 圆角 + 选中块与卡片同色 + 内凹圆弧 + 卡片 `0px 10px`、加号与文字同中线、标题里没有编辑/删除按钮。改这套样式前先跑 `g74`。
