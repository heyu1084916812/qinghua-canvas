## 2026-11-17 Key 分组改圆润文件夹标签（#1144 三轮）

- 用户第二轮否掉了斜切梯形：「形状我要这种圆角的」，并要求**选中的分组自动排第一列**、修「加号和文字不在同一排」。叠加起来最省事的结构是：渲染时把当前分组提到数组首位 → 选中标签永远贴左边 → 卡片左上角直角、只需在**右下角**画一条内凹圆弧，不必为「标签在中间」补左右两半。
- 参考图逐像素量出来的真几何（2026-11-18 复测）：**两枚标签顶边齐平、等高**（不是选中更高）；两枚标签之间是一道缝：顶部宽 38px，往下 10px 内迅速收到 12px，再往下只剩 5px，一直通到卡片顶边 —— 也就是「窄缝 + 顶部 V 形缺口」，中途怀疑过「选中立起来」「大圆角卡片」，都不对。
- 做 V 形缺口的正解：标签自身只留 6px 间距，再给每个标签的上角叠一块「页面底色 + 1/4 椭圆」的伪元素把角啃掉（16px 宽 × 整枚标签高）。用 `radial-gradient(ellipse W H at 0 100%, transparent 99%, var(--bg-canvas) 100%)`：圆心压在「标签竖边 × 卡片顶边」交点，弧就从顶边一路削到底，两枚标签的弧自然拼成 V。不要用「外撇三角形/梯形 + clip-path」，那是斜切，用户明确否掉了。
- 等高就没有加号对齐问题：标签 44px、按钮 34px、`margin-bottom: 5px`，三者中心相等（实测 468/468/468）。上一轮「选中 56 / 未选中 40」正是把加号逼到两边各差 4px 的根因。
- 未选中标签底色不能靠 `color-mix(--bg-subtle, --bg-canvas)`：浅色主题页面比卡片**更亮**、深色相反，一条相对关系会在浅色下算出比卡片还浅、几乎看不见的底。按主题各给一值（新增 `--bg-tab-idle`：浅 #f2f2f2 / 深 #1e1e1e，只比卡片深一小档），令牌仍集中在 `tokens.css`。
- 啃角用的是 `--bg-canvas`（标签栏底下就是页面底），所以换页面底色时这条伪元素要跟着改；`tokens.css` 里的 `--bg-tab-idle` 只管未选中标签自己的填充。
- 选中态不再需要独立背景层（等高、等宽都不动），组件里的 `ResizeObserver / 指示器` 整段删掉——`background` 直接挂在标签上，切换时只有 `background-color` 180ms 过渡。
- 冒烟里给这套造型钉了 4 条：选中排第一 / 44px 标签、12px 顶角 + 选中标签与卡片同色 + V 形缺口（伪元素 16px + `radial-gradient`）+ 卡片 `0px 10px`、加号与文字同中线、标题里没有编辑/删除按钮。改这套样式前先跑 `g74`。

## 2026-11-18 Key 分组移植 folder_tabs_ui.html（#1144 四轮）

- 用户给了 `folder_tabs_ui.html` 要求「用这个代码的核心形状和动效还有文字变换效果」。它有三个可搬的东西：① SVG 路径画的斜边梯形（slope 15 / 顶角 12 / 底角 11，相邻 `-18px` 负边距嵌套）；② 一支阻尼谐振子把选中标签的 x / w / h 逐帧写成一条 path（刚度 340/340/420、阻尼 22/22/21，`vx*0.0075` 做 ±6.5px 倾斜，切组时 `vh=-68` 先压后弹）；③ 选中时文字层 `translateY(-1.5px)` + 600 字重。
- **这套动效和「选中分组排第一列」互斥**：形变层是滑到被点标签上的，一重排选中项就永远在 0 位置，动效等于不存在。以最新需求为准，顺序改回分组原序，并在交付里写清楚。
- SVG 的 `viewBox` 必须等于标签真实像素宽高（`preserveAspectRatio="none"` 才行），否则圆角会被横向拉伸；所以要 `ResizeObserver`/layout effect 量宽高，改名、加徽章都要重量。
- 三层 z-index 是硬约束：静止梯形 1、形变层 5、文字 10；标签本身**不要**设数值 z-index，否则各自建立层叠上下文，形变层插不进中间。
- **StrictMode 陷阱**：dev 下组件 mount → 卸载 → 再 mount，卸载清理里 `cancelAnimationFrame` 后必须把 `raf` 与 `initialized` 一起归零，否则第二次挂载看到 `raf != 0` 再也不启动动画（本轮实测：路径永远停在 x=0，还以为 rAF 坏了）。
- 窄缝/啃角/等高卡片那几版（三轮）全部作废，别再往回改：参考图量出来的「缺口形状」其实就是这套斜边梯形嵌套的视觉效果。
- 动画相关断言怎么写：不要断言某个瞬间的绝对坐标，改成「记录若干帧的 right/top，断言 起点 < 峰值 > 终点（过冲）且 top 中途变大再回到静止」。冒烟里只钉「形状是 SVG 路径 + 形变层存在 + 卡片直角 + 加号同中线」这类稳定事实。

## 2026-11-18 SettingsPage 按卡拆分：第 3 步「映射卡」

- **「这张卡的 state」未必真是这张卡的**：`modelAddOpen / newModelName / newModelCategory / newModelVendor` 看着是映射卡的表单态，但 `channelActions.addGlobalModel` 要读它们。想让它们搬进卡，只能把 `addGlobalModel / removeGlobalModel` 一起搬走——判断依据是「这两个动作还有别的调用方吗」，答案是没有，所以整组搬（连 `ChannelActionState` 三个字段与 `setNewModelName / setModelAddOpen` 两个端口一起删）。搬完 `channelActionCoordinator.test.ts` 里那两条用例也跟着搬到 hook 测试，别直接删。
