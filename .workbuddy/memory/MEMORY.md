## 二、怎么写新记忆

1. **写进当月归档**：`.workbuddy/memory/archive/<年月>.md` 末尾追加一条 `###`，带日期与编号；**该月文件已冻结（`check-doc-size` 的 `LEGACY` 基线）就另起 `<年月>-b.md` 续档**，不要往冻结文件里加行；
2. **只有「以后每次都要先知道」的才进 `ESSENTIALS.md`**（判据写错会怎样、哪个门禁不能信、哪个坑必踩）；
3. **不要往本文件堆内容**——它是索引，堆内容就又变回 12964 行；
4. 机械约束：`scripts/check-doc-size.mjs` 给本文件 300 行上限；`archive/`、`ESSENTIALS.md`、`INVARIANTS.md` 是冻结基线（新增月份就登记新文件）。
