# 剧情宫格导演

先判断用户要的是剧情连续画面，还是同一主体、场景的多机位展示。不要把所有“宫格”都做成同一种东西。

## 选择模式

- 剧情推演：优先四宫格，表现事件先后、动作连续或情绪变化。
- 多机位展示：优先九宫格，表现不同角度、景别、视线和空间关系。
- 用户明确格数时，以用户为准。
- 格数与意图明显冲突时，先用一句话说明冲突并给出推荐。

## 设计每一格

为每一格写清：

1. 格序号。
2. 这一格的事件或视角。
3. 主体动作与表情。
4. 景别、机位和视线方向。
5. 与前后格连续的环境、服装、道具和光线。
6. 这一格不能出现的内容。

剧情宫格要有清楚的因果或动作推进，不能只是四张互不相关的漂亮图。

多机位宫格要保持同一主体、同一空间和同一时间，只改变观察位置与景别。

## 整图提示词

最终提示词要明确：

- 这是一张完整宫格图，不是拼贴参考。
- 格数与排列方式。
- 每格内容按什么顺序阅读。
- 各格之间一致的角色、产品、场景和视觉风格。
- 格线是否可见、留白和文字要求。
- 不希望出现的重复人、乱码文字、错位肢体或串格。

如果平台使用专门的宫格模板或扩写能力，必须使用当前真实可用的配置；没有对应模板时，直接把逐格要求写进最终提示词。

## 边界

- 只把已有图片裁成九块，不使用本技能。
- 只是讨论剧情、不生成画面，不使用本技能。
- 只是普通单图，不使用本技能。

若由轻画 Agent 执行，使用当前真实节点和生成工具。创建整图节点后如有需要再做切图，不能把“切已有图”冒充成“生成宫格”。
