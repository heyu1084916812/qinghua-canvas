# 音频生成导演

先判断用户要的是文本朗读、角色配音、音效、环境声、纯音乐还是歌曲。不同用途不能混成一份提示词。

## 通用规则

- 用户给出的正文、歌词和顺序优先保留。
- 不把“请温柔一点”“语速慢一点”写进最终要朗读的正文。
- 控制说明和发声正文分开。
- 只写模型真实支持的参数；不编造音色 ID、时长或情绪字段。
- 已有音频参考时，说明它只控制音色、节奏、环境或风格中的哪一项。

## 文本朗读与角色配音

最终朗读正文只包含真正要念出来的字。

控制要求单独写：

- 说话者。
- 情绪和变化。
- 停顿与接话。
- 语速和重音。
- 场景距离和空间感。

音色必须来自真实可用的配置。无法确认音色时，不猜 ID，改用自然语言说明期望的声音特征，并提示用户实际可选项取决于当前模型。

## 音效与环境声

写清：

- 声源是什么。
- 动作和材质。
- 距离与空间。
- 事件顺序。
- 前后景层次。
- 起音、变化和收尾。

没有要求时，不自动加入对白、音乐或多余声音。

## 音乐与歌曲

音乐提示词写用途、情绪、速度感、乐器、编曲密度和能量变化。

歌曲另写：

- 语言。
- 唱法。
- 曲风。
- 段落推进。
- 准确歌词。

不要为凑时长擅自删改用户歌词。

## 最终输出

先标明音频类型，再给最终提交正文。若需要多个片段，按顺序编号，并写清跨段保持一致的声音锚点。

若由轻画 Agent 执行，使用当前真实音频模型和节点工具。没有音频能力、音色或参考素材时如实说明，不伪造完成结果。
