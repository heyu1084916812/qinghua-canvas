# #1196 Agent 新会话首屏

## 设计

空会话不再只显示一行说明，改为画布 Agent 的能力首屏：

- 主标题「从一句话，到一张画布」
- 一句说明拆步骤、调用 Skill、搭建与执行节点
- 三个可点击起稿入口：生成一张图、搭建工作流、调用 Skill
- Skill 数量、画布节点、参考素材、自动执行四个能力标签

点击建议只把完整起稿句写入输入框并聚焦，不直接发送。

## 验证

- `1440×900 / 1024×700 × 明暗` 四组合 G1196 均 `4/4`。
- 三个建议卡命中高度均不小于 44px，首屏无横向溢出。
- 点击「搭建工作流」后输入框获得焦点并包含起稿句。
- Agent welcome / conversation / panel view / MentionEditor 定向测试 `44/44`。
