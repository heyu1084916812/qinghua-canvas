# 模型映射「空分类不留空长表」取证（2026-11-18 / #1150）

**问题**（用户截图）：切到「视频 0」这种**一条都没有**的分类时，映射面板仍占着整块固定高度，
看起来像一张 460px 的空白表单。

**改法**：面板照旧始终渲染（#1146：分类行数不同，表壳随内容伸缩会让页面跳），
但 `activeRows.length === 0` 时：

- 收掉表头（前端显示模型 / 真实模型 / 常用设置）
- 行区塌成一行提示「这一类还没有前端模型」（`data-route-map-category-empty`）
- 面板内边距收到 `--space-3`

## 一、实测（`scripts/probe-mapping-tab-jump.mjs`，四组视口 × 明暗）

| 档位 | 面板高度（改前） | 面板高度（改后） |
| --- | --- | --- |
| 视频（0 行） | 384（与有行档同高，空长表） | **44.8** |
| 对话 / 图片 / 音频（有行） | 384 | 384（不变） |

1024×700 下：有行档 284、空档 **44.8**。四组 `VERDICT: pass`（有行档高度恒定 ✓ / 空档已收窄 ✓ / 底部切档后标签位移 0px ✓）。

## 二、取舍（要跟用户说清楚）

空档收窄后，**在有行档与空档之间切换时面板高度会变**（384 ↔ 44.8）。
这是「空档不许留长表」的必然结果：要么保持等高（就是用户截图里那张空长表），要么空档收窄（会有这一下高度变化）。
有行档之间切换仍然等高、不跳。
