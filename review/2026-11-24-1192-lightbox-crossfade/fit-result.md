# #1192 多选灯箱切图适配回归

## 用户现场

- 横向图单独打开：`1672 x 941 / 72%`
- 竖向图单独打开：`1086 x 1448 / 47%`
- 多选灯箱从横向图切到竖向图：错误沿用 `72%`，竖向图高度超出舞台
- 原始截图：`before-fit/`

## 修复判据

- 用户尚未手动缩放或平移：每张图按自身自然尺寸和同一舞台重新 fit。
- 用户已经手动缩放或平移：切图保留当前 zoom，并让新旧媒体中心重合。
- 新开灯箱仍只执行一次初次 fit，不重播开灯箱 FLIP。

## 验证

- `g795` 使用 `1672 x 941` 与 `1086 x 1448` 两张真实可解码 PNG。
- `1440 x 900 / 1024 x 700 x 明暗` 四组合均 `10 / 10` 通过。
- 未操作切换后，竖向图在 `1440 x 900` 为 `47%`，在 `1024 x 700` 为 `33%`。
- 手动缩放后切换，zoom 不变，本次实测媒体中心误差小于 `1px`。
- 四组合截图：`after-fit/`
