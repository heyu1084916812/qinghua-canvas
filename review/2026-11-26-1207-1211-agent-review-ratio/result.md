# #1207 / #1211 验收提示与生成前比例

- 验收：`resultsReadyAt` 直接驱动计划卡 sticky 验收面板，显示“结果已生成，正在等你验收”和“验收通过，继续”；长计划滚到底部仍保持可见。
- 比例：从用户原话识别整组唯一比例并写入 `AgentTaskRef`；`applyPlan` 前覆盖新建图片生成节点；`runNode / runFrom` 前再次检查，不一致直接拒绝。
- 边界：视频节点不参与图片比例覆盖；普通任务未出现“统一 / 都 / 全部 / 每张”等范围词时不把单个比例推断为整组约束。电商图片任务例外：未写比例时整套默认 `1:1`，同句出现多个比例则不擅自统一。
- 结构：比例解析、生成计划约束、落地模型自检分别拆分，所有模块在既有行数预算内。
- 验证：G1205 四组合均 4/4；全量 Vitest 6711 passed / 1 skipped；截图和 smoke 日志在本目录。
