# #1194 选中上游后拖动下游的连线跟随

## 根因

先选中上游节点会让相关边进入高亮态。拖动下游节点时，React Flow 因选中态变化替换边 `<path>`；direct-drag follower 仍持有旧 path 元素，后续每帧 `d` 写入都落在已卸载节点上，可见新 path 因而停在原位。

## 修复

`flowDragDomFollower` 为每条边保留 edge id。写入前若旧的 path / hit path 已断开，就按 edge id 从当前 React Flow DOM 重新绑定可见线、命中线和删除按钮，再按当前位移重算贝塞尔。

## 验证

- G58 按用户路径执行：先点左侧提示词节点，再按住并拖动右侧生成节点。
- 拖动中边 `d` 与拖动前不同，目标端点跟到移动后的节点。
- `1440×900 / 1024×700 × 明暗` 四组合 G58 均 `39/39`。
