# Key 分组文件夹标签（#1144 二轮）

## 需求（用户 2026-11-17）

1. Key 分组改成 folder tabs UI；
2. 去掉编辑重命名和删除按钮，只保留一个文件夹标题；
3. 点其他标题就滑过去；
4. 文字框和文字自适应，输入框不能太长；
5. 去掉标题前面的小圆点；
6. 选中态就是一个梯形，梯形里只有文字和优先级；
7. 其他分组标题没有背景色；
8. 补充：双击分组是编辑名称，右键分组标题出菜单（编辑 / 删除）。

## 结果

- 选中态只有一块梯形：标题本身透明，梯形是标题栏里一块独立的指示器，位置与宽度从真实
  DOM 量出来（`ResizeObserver` + 字体就绪后重测），切换分组时用 `transform / width` 220ms
  滑过去；与下方模型列表同底色（`--bg-subtle`）并底边相接。
- 标题里只剩名称与优先级：删掉状态点、重命名按钮、删除按钮，以及整段「展开专属操作」的
  `max-width` 动画。
- 未选中标题无底色，只有文字；悬停只变色不加底。
- 宽度随文字：标题 `max-width: 220px` + 省略号；重命名输入框用镜像文字撑开，
  `max-width: 160px`（实测「默认分组」66px）。
- 改名与删除换了入口：选中标题双击进入改名（Enter 提交 / Esc 取消），右键标题出菜单
  `编辑 / 删除分组`；删除在菜单内二次确认，按 `groupId` 精确删除，只剩一组时禁用，
  Esc 只关菜单（不再连带关掉整个设置页）。

## 为什么这么做

- 为什么用一块浮动梯形，而不是给每个标题画背景：用户要的是「选中态就是一个梯形、其他没有背景」。
  给每个标题各画一块再靠宽高动画对齐，切换时会出现两个形状同时缩放；改成单块指示器后，
  只有它在动，宽度变化（选中标题多出优先级）也跟着一起过渡。
- 为什么标题不加粗：加粗会改变文字宽度，切换瞬间标题栏会整体抖动；选中与未选中的区别
  交给颜色（`--text-1` / `--text-2`）与那块梯形。
- 为什么删除要留在右键菜单：标题上不能有按钮，但删掉一组 Key 是常规操作；右键菜单是
  设置页已有的模式（渠道右键菜单同款样式），且菜单内二次确认比系统 `confirm` 更贴近现在的视觉。
