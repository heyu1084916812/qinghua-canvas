# Key 分组文件夹标签（#1144 二～四轮）

## 需求

**二轮**：Key 分组改 folder tabs；去掉状态点与编辑 / 删除按钮；点其他标题有动效；文字与输入框自适应；
选中态里只有名称与优先级；双击改名、右键出「编辑 / 删除」菜单。

**三轮**：形状要圆角、选中的分组排第一列、修「加号和文字不在同一排」。

**四轮（2026-11-18，用户给了 `folder_tabs_ui.html`）**：
「用这个代码的核心形状和动效还有文字变换效果」。

## 结果（对齐 `folder_tabs_ui.html`）

- **形状走 SVG 路径**：每枚标签一张静止梯形（两侧 15px 斜边、顶部 12px 圆角、底部 11px 圆角），
  相邻标签用 `-18px` 负外边距互相嵌套；viewBox 按标签**真实像素宽高**建（`preserveAspectRatio="none"`，
  尺寸==viewBox，所以不会被拉伸变形）。
- **选中标签是一块共享的形变层**：位置 `x`、宽度 `w`、高度 `h` 三个阻尼弹簧逐帧写进一条 `<path>`，
  画在静止梯形之上、文字之下。切组时 `x` 滑过去（实测 146 → 峰值 242.9 → 稳定 234.9，有回弹），
  滑行中按水平速度产生最多 ±6.5px 的顶部倾斜（液态惯性），`h` 先被压 1.5px 再弹回
  （`top` 2 → 3.5 → 2）。
- **文字变换**：选中时 `.keyGroupTabInner` 整体 `translateY(-1.5px)`（32ms 弹簧曲线）+ 字重 600 +
  颜色渐变；未选中归位。实测选中标签文字中心比相邻标签高 1.5px。
- **选中 = 卡片同色**：形变层填充 `--bg-subtle`，与下方「模型列表」卡片无缝相接，卡片左上角直角。
- 未选中标签填充 `--bg-tab-idle`（浅 #ededed / 深 #1b1b1b），悬停换 `--bg-hover`。
- **不再重排标签**：`folder_tabs_ui.html` 的动效就是「形变层滑到被点的标签上」，重排会让它原地不动。
  选中项不再强制排第一列（上一轮的口径被这轮的动效需求取代），标签顺序始终等于分组顺序。
- 其余口径不变：标题只有名称 + `P<优先级>`、宽度自适应（≤220px 省略号）、双击改名（输入框 ≤160px）、
  右键「编辑 / 删除分组」（菜单内二次确认、按 `groupId` 精确删除、只剩一组时禁用）。

## 为什么这么做

- **为什么把几何放进 SVG 而不是 CSS 圆角**：这套形状要「斜边 + 双圆角 + 底边贴卡片」同时成立，
  而且选中态要在跑动中被弹簧改写成另一个梯形；CSS 画不出「斜边与圆角咬合」，SVG 路径可以精确到像素。
- **为什么选中态要单独一层**：形变层要能盖住前一枚标签的斜边、又要压在文字下面，
  用 `z-index 1 / 5 / 10` 三层；标签本身不设 z-index，避免各自建立层叠上下文后互相插队。
- **为什么要量真实宽高**：`viewBox` 不等于实际尺寸时，圆角会被横向拉伸成椭圆；改名、加徽章都会改变宽度。
- **为什么不重排**：见上；重排会让形变层永远停在 0 位置，动效等于没有。
- **StrictMode 的坑**：开发模式下组件会被 mount → 卸载 → 再 mount，我们的卸载清理里
  `cancelAnimationFrame` 之后必须把 `raf`/`initialized` 一起清掉，否则第二次挂载看到 `raf != 0`
  就再也不启动动画（本轮实测踩到：动效完全不跑，路径停在 0）。

## 复核要点（给用户）

- 点另一个分组：选中那块形状是**滑**过去的，滑的时候会轻微倾斜、落位时有一点回弹；
- 选中标签的文字会比旁边的**抬起来一点**（1.5px）并变粗；
- 选中标签与下方卡片同色、底边无缝，左上角是直角；
- 标签顺序就是分组顺序（不再自动把选中的挪到第一列）。
