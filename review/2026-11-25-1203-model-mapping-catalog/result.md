# #1203 全局前端模型目录

## 最终形态

- 「模型映射」标题右侧齿轮打开完整前端模型目录。
- 新增区常驻：前端模型名称、分类、图标和添加。
- 已有模型按「对话 / 图片 / 视频 / 音频」切换，只渲染当前分类。
- 每个模型是与上方图标选项一致的胶囊：厂商图标 + 前端名称。
- 自定义模型在胶囊内部右侧显示 `×`；内置模型没有删除入口。
- 双击自定义模型名称进入原位编辑，Enter / 失焦提交，Esc 取消。
- 常用 / 不常用仍只在映射行操作，目录不重复提供开关。
- 目录外壳和分类内容区不再使用描边，只保留背景与阴影层级。

## 稳定身份

- `PresetModel.id` 继续作为节点、渠道 `modelMap` 键和路由使用的稳定逻辑名。
- `PresetModel.label` 只负责前端显示名。
- 重命名只更新 `label`，所以旧节点、旧映射和外部选择值不需要迁移。
- 内置模型不可删除，也不可改名；自定义模型可删除、可双击重命名。
