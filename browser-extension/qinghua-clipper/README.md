# 轻画 Clipper 浏览器扩展

轻画 Clipper 是 Chrome / Edge 的 Manifest V3 扩展，只做一件事：

> 开启拖拽收藏后，把网页图片拖到页面中央，松手即收藏到本机轻画。

扩展没有网页收藏、快捷键、右键菜单、地址输入、令牌输入或设置页。

## 工作方式

1. 扩展安装时一次授权全部 HTTP/HTTPS 网页；顶部“拖拽收藏”是唯一的全局开关。
   打开一次后，不再需要逐站点授权或逐网页开关。
2. 页面平时没有悬浮控件；开始拖动图片时才出现中央投放框。
3. 图片松手后，扩展把页面 URL、图片 URL 和标题发送到本机轻画。
4. 轻画接收端只监听 `127.0.0.1:53684`，扩展通过 `/pair` 自动获取当前临时令牌。
5. 图片进入“我的素材 → 轻画插件”，可继续加入参考、Agent 对话或画布。
6. 桌面端只在图片真正落库后确认移除待收项；失败项会留在队列并自动重试，不再静默显示为空。

浏览器重启、轻画重启后都会自动重新配对，不需要手填地址或令牌。

## 权限

- `storage`：保存拖拽开关和自动配对令牌。
- `scripting`：注册、启用或停用拖拽脚本。
- `host_permissions`：访问本机 `http://127.0.0.1:53684/*`，以及全部 `http://*/*`、`https://*/*`
  普通网页。安装或权限升级时浏览器会显示一次“读取和更改所有网站数据”的确认。

扩展不读取 Cookie、历史记录或浏览器账号数据，不使用 `<all_urls>` 简写。
自动配对接口只接受 `chrome-extension://` / `extension://` Origin。
`chrome://`、`edge://`、扩展商店等浏览器保护页不允许任何扩展注入，这是浏览器安全边界。

## 本地安装

在项目根目录双击：

`scripts\install-clipper-local.cmd`

脚本会把扩展复制到系统“文档”目录：

`QinghuaClipper\extension`

然后打开 Chrome / Edge 扩展页和资源管理器。浏览器安全边界要求最后确认一次：

1. 开启开发者模式。
2. 点击“加载未打包的扩展程序”。
3. 选择 `QinghuaClipper\extension`。

Chrome / Edge 会记住这个目录，后续启动不需要重新选择目录。

## 应用内更新

轻画桌面端会把当前发布版扩展作为应用资源打包。扩展自动配对时会上报自身
`manifest.version`；当应用内置版本更高时，“我的素材 → 轻画插件”会显示一条紧凑的更新提示。

点击更新后，应用先把新版复制到临时目录并校验，再替换同一个稳定目录：

`QinghuaClipper\extension`

随后应用会打开 Chrome / Edge 扩展管理页和这个目录。浏览器安全边界要求最后一步仍由你确认：

1. 在扩展卡片上点击“重新加载”。
2. 打开扩展弹窗确认拖拽开关仍是你需要的状态。
3. 下一次自动配对后，轻画面板会消失更新提示。

应用不会写入浏览器的 `User Data`，也不会静默重载扩展。若你当初加载的是其他目录，
需要重新选择上面的稳定目录；应用不会猜测并覆盖其他路径。

不要直接复制文件到浏览器 User Data 下的 Extensions 目录；浏览器不会把裸复制识别为已安装扩展。

## ZIP、CRX 与商店分发

- ZIP 是商店提交包，也是本地解压后“加载未打包的扩展程序”的包。
- Chrome 的“打包扩展程序”会生成 `.crx` 和 `.pem`，但 Windows Chrome 默认阻止来自商店外的 CRX 安装。
  因此不能把 `.crx` 当作通用的一键安装分发格式。
- 要实现普通用户真正的一键安装，仍需 Edge Add-ons 或 Chrome Web Store 上架。

构建 ZIP：

```powershell
npm run package:clipper-extension
```

产物位于 `release/qinghua-clipper-0.4.5.zip`。

桌面发布构建完成后，可在项目根目录运行真实更新门禁：

```powershell
npm run check:clipper-update
```

它使用隔离数据目录和临时稳定目录，不会修改真实 Documents、浏览器 `User Data` 或当前浏览器扩展。

验证一次开关后两个不同域名都能注入：

```powershell
npm run check:clipper-all-pages
```

## 排错

- 更新到 0.4.5 后，扩展管理页可能要求重新确认“在所有网站读取和更改数据”；确认一次即可。
- 开关打不开：在扩展管理页确认站点访问权限是“在所有网站上”，不是“点击时”。
- 出现 “Only permissions specified in the manifest may be requested.”：扩展页里点一次“重新加载”，
  确认运行的是 0.4.5 或更新版本。
- 页面中不出现投放框：确认开关已开启，并刷新打开扩展前已经存在的旧标签页。
- 拖入后提示轻画未打开：先启动轻画桌面端；扩展会自动重新连接。
- 图片没有生成卡片：确认当前运行的是包含待收快照/确认协议的新桌面版；面板打开后会每 3 秒重试，
  导入失败不会再把队列项提前丢弃。
- 若提示 `Command clipper_pending_snapshot not found`：说明桌面外壳还是旧进程。新版前端会临时
  回退旧队列继续导入，但可靠重试和成功确认要重启桌面版后才会启用。
