② 派生数据与处理函数（约 300 行）、③ 各处 `onXxx={() => void ...}` 的胶水。只搬 state 等于把账从左口袋挪到右口袋。

**下一步的可执行方案**（按收益排序）：
1. `SettingsChannelEditorView`：把编辑器 157 行 JSX 整块搬走（约 45 个 props，净减 ~110 行）；

3. 真正的收益要按**卡片**拆（连接 / 分组 / 映射 / 测试），每张卡自带 state + handler，
   页面退化成协调器 —— 这是 2~3 小时的改动，且要逐卡跑回归，不能顺手做。

**已知阻塞**：编辑器那段 JSX 引用了 **77 个页面作用域标识符**，抽成组件要写 77 个带类型的 props（约 90 行接口），
