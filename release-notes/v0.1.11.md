## 0.1.11 · 数据隔离、Agent 消息拆表、Canvas MCP 与记忆闭环（2026-10-30）

> 本版从 `0.1.10` 升级到 `0.1.11`，继续使用原更新私钥签名。

- 正式版继续读取 `storage-location.json`，开发版改用独立的 `storage-location.dev.json`，
  两边切换资源位置时不再互相覆盖。
- 开发版首次启动默认使用项目根目录已有的 `data-v2`；浏览器开发服务读取同一份开发配置，
  不会再因为正式版自定义了数据目录而连接正式版主库。
- 正式版仍支持用户自行选择正式主库；安装、卸载和更新安装包不会移动或删除现有数据根。
- 发布验收的临时数据隔离继续只作用于放行测试，不影响正常桌面启动。
- Agent 会话元数据与消息正文拆成两张逻辑表；旧库启动时一次性迁移并校验，列表不再携带整段历史。
- V2 存储 schema 升到 3，旧资源根会自动同步 manifest；共享存储协议升到 8，旧后端会被明确拒绝。
- 新增本机 Canvas HTTP 网关和 MCP stdio 适配器，外部可读取画布、创建低风险节点计划、移动与排列节点；
  删除、改节点、付费生成和记忆写入仍需在应用内确认。
- Agent 记忆记录来源会话、进入上下文次数和最近使用时间；正式版与开发版继续使用各自的存储配置。
