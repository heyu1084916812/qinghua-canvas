## 0.1.17 · 首屏性能、CLI 自动化与真实图片画布（2026-11-08）

> 本版从 `0.1.16` 升级到 `0.1.17`，继续使用原更新私钥签名。

**首屏与存储**

- 存储项目数改为一次 `queryPage` 总数读取并排除回收站，素材计数只投影最小字段、批量扫描且不读 payload。
- 存储面板重开先用本会话快照显示，再后台刷新；未知 MIME 归入“其他”，不再误算成音频。
- 总日志和画布日志缓存首屏，筛选切换的迟到响应不会覆盖当前结果；画布日志合并连续写入刷新。
- 存储、全局日志和画布日志分段发布；335 项目 / 1,400 素材 / 500 运行记录隔离 release 实测
  快速 `216ms`、完整 `589ms`、存储重开 `68ms`、全局日志 `92ms`、画布日志 `201ms`；
  资源目录、缓存与全部分类字段回填，错误和溢出为 0。

**CLI**

- 安装 / 登录窗口结束会自动重检、继续登录或查询状态；空状态命令明确跳过，不再要求用户重复点击。
- 可见窗口由壳持有并等待退出码，进程树只按本方 PID 终止；媒体输入和 RunningHub 多产物走受控落库。

**Canvas MCP**

- 新增真实 release 联调门禁：隔离 V2 store 中打开种子画布，独立 stdio harness 完成
  `initialize → tools/list → tools/call(readGraph)`，读回 2 个节点和 1 条连线。
- 删除节点、付费生成和记忆写入仍不开放给外部 MCP；隔离 profile 下 gateway token 与应用配置目录一致。

**画布**

- AgentHost、灯箱、文本编辑器和日志改为真实懒加载边界，所有 JS chunk 低于 500KB。
- 真实图片性能固定 150 张唯一 PNG/WebP、300 节点 / 500 连线；隐藏浮层不再逐帧订阅视口，
  full/coarse 在缩放停止后才切换。连续三次正式报告通过，平移最高 14.0ms、缩放最高 14.2ms。
- 3D 仍为明确 deferred，不显示为可用能力。

**验证**

- 全量 Vitest `642 files（641 passed / 1 skipped）/ 5397 tests（5396 passed / 1 skipped）`；
  `npm run check`、`smoke:critical` 97 项通过。
- `verify:mcp:release`、`verify:storage:release`、`verify:cli:release` 均通过。
- 发版脚本支持可选 Windows Authenticode 签名，并与 Tauri updater Ed25519 签名分开记录；
  未提供代码签名证书时明确输出 `NotSigned`，不冒充已签名。
- 本地安装包 `44,050,916 B`，SHA-256
  `CE302F80037ED329D66BA8AF54C7812DF976674916826337ABC970D32065FB5A`；release 壳 12/12。
- 真实已登录渠道、CLI、Pinterest、外部 MCP harness、干净机器安装和远端发布仍需外部账号或用户确认。
