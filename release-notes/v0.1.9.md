## 0.1.9 · Agent 协作、记忆套件与生成链路加固（2026-10-29）

> 本版从 `0.1.8` 升级到 `0.1.9`，继续使用原更新私钥签名。

**Agent 与画布**

- Agent 支持持久任务计划、逐步状态、中途确认、排队与引导投递；任务结束后状态与输入框保持稳定。
- 增加画布空间工具、节点移动与尺寸调整、视觉输入和只读视觉验收；生成结果可点击放大查看。
- 自动生成模式只保留计划确认，生成结果验收按用户设置执行；取消任务会同步结束 Agent 的活动状态。
- 画布浮球位置独立保持，面板重新打开时围绕浮球在可视区域内展开。

**模型服务与路由**

- 模型服务继续支持多 Key 分组、同模型合并、分组优先级和常用模型过滤。
- 修复文本工具、豆包图片与 SoonStudio Gemini 等异步任务的模型选择、任务号解析、轮询和直接产物落库。
- 区分模型验证超时与生图任务超时；已提交的付费请求不会因客户端超时自动重发。

**上下文、日志与工作台**

- 新增品牌、产品、角色与自定义套件，支持版本化记忆、项目作用域和上下文预算。
- 总日志与漫剧日志共用运行记录，可按工作台筛选；修复日志第二分类读取和跨项目查询。
- LibTV 技能目录按真实正文与分类重建缓存；无正文条目不再占用技能正文入口。
- 调整浅色/深色节点表面、画布背景、批量与对比节点；补充多选灯箱缩略图、切换与旋转体验。

**桌面与发布**

- 继续使用可配置 V2 资源根、V1 自动升级和资源根更换位置流程。
- 安装包执行三方版本一致性、Ed25519 签名核对和 release 产物真机启动门禁。
