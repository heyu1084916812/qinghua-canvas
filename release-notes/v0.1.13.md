## 0.1.13 · Agent 代码拆分与可隔离发布门禁（2026-11-02）

> 本版从 `0.1.12` 升级到 `0.1.13`。`0.1.12` 是本地可靠性回滚点，未发布。

**Agent 代码拆分**

- Agent 工具 schema 与能力发现拆到 `toolCatalog.ts`，执行文件 `tools.ts` 从 2380 行降到 1299 行；旧导出继续兼容。
- 画布只读摘要、素材信息和结果读取拆到 `canvasReadTools.ts`，结果 MIME、旧产物失败判断等行为保持不变。
- Agent 生成任务、活动过程、状态展示拆到 `AgentActivityViews.tsx`；排队列表、引导、编辑和继续排队拆到 `AgentQueuePanel.tsx`。
- `AgentPanel.tsx` 从约 6400 行降到 5846 行，DOM、className、文案、按钮顺序和现有交互保持不变。
- 工具目录和执行层保持单向依赖；新增兼容测试确认旧入口与新模块仍引用同一份实现。

**发布门禁**

- release 实机自检在没有关闭开发壳的情况下可以独立启动、独立连库并完成 `11/11`。
- 只有 `QINGHUA_RELEASE_GATE=1` 时才跳过单实例锁并使用独立共享存储端口；正常启动仍使用 `18765` 和单实例保护。
- release gate 默认使用 `18767`，支持显式端口覆盖；WebView、shared-store、维护请求和安装器门禁使用同一端口。
- 自检同时核对后端 health、前端实际端口和临时 `data-v2` 目录，不会连回真实用户库。
