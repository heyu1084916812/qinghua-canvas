## 0.1.10 · 升级源选择与全新安装 V2 修复（2026-10-29）

> 本版从 `0.1.9` 升级到 `0.1.10`，继续使用原更新私钥签名。

**升级迁移**

- 启动时先查找有真实记录的旧 V1（优先 `%LOCALAPPDATA%\com.qinghua.canvas\shared-store-v1`），
  不再把升级瞬间新建的空 `data` 当成迁移源。
- 空 V1 根会明确拒绝迁移，不会再生成 `channels=0` 却标记 complete 的伪成功报告。
- 旧 `0.1.9` 若已留下空 `data-v2`，会先把这份空根隔离备份，再从真实 V1 重新迁移。

**全新安装**

- 全新安装直接初始化 `data-v2`，首次启动就使用 SQLite V2，不再先写一份 V1 JSON。
- 正式安装结构统一为产品文件夹内的 `qinghua.exe + uninstall.exe + resources + data-v2`。
- “更换位置”允许直接选择包含 `data-v2` 的产品文件夹，不再误报“目录非空但不可识别”。

**发布检查**

- 发布后验收新增 Release 标题与正文编码检查，出现连续问号或替换字符会直接失败。
- Windows 应用内更新改为静默安装模式：下载和验签后短暂退出并自动重开，不再显示系统安装面板。
