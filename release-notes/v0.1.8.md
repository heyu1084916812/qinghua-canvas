## 0.1.8 · V1 自动升级与资源根更换位置（2026-10-24）

> 本版从 `0.1.7` 升级到 `0.1.8`，继续使用原更新私钥签名。

**V1 自动升级**

- 更新后首次启动识别到 V1 时，自动迁移到安装目录旁的 V2 资源根，不需要用户选择目录。
- 迁移完成后再次校验 SQLite、素材文件、完整 SHA-1、引用和派生文件。
- 校验通过后在 V2 首次成功载入时自动删除 V1，只保留 V2；任一步失败都保留 V1。

**更换位置**

- 设置页的“切换已有目录”改为“更换位置”。
- V2 更换位置会完整复制资源根、执行 SQLite checkpoint 和全量回读校验，成功后切换并删除旧根。
- 手动把 data 移到其他盘后，旧路径不存在时进入恢复模式；选择移动后的目录只做完整性检查，
  不再复制，也不会在旧路径创建空库。

**验证**

- shared-store 31/31、Tauri 43/43、Vitest 3086 passed / 1 skipped；`npm run check`、`npm run build` 通过。
- 三条真实链路通过：V1 自动升级并清理旧库、V2 换位置并清理旧根、手动搬走后校验接管。
- Windows 安装包使用原更新私钥签名并通过 Ed25519 验签；release 启动 11/11，
  0.1.7 → 0.1.8 覆盖安装 / 数据保留 / 卸载 14/14。
