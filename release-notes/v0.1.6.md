## 0.1.6 · 模型服务与画布体验更新（2026-10-24）

> 本版从 `0.1.5` 升级到 `0.1.6`，重新构建并签名 Windows NSIS 安装包。应用内更新仍读取 GitHub Releases 的稳定清单地址。

**模型服务**

- 模型服务列表改为紧凑单行布局，内置服务与自定义服务共用统一入口，支持搜索、启用状态筛选、拖动排序和右键操作。
- 服务编辑改为设置区域内的居中浮层，统一渠道图标、编辑入口和保存体验。
- 渠道支持多个独立 Key 分组；同一模型自动合并，并按分组优先级逐一尝试。
- 新增全局前端模型设置、常用/不常用模型过滤和映射测试入口；画布、Agent、默认参数与电商工作台共用同一套过滤规则。

**画布与 Agent**

- Agent 浮球位置保持为独立锚点；关闭面板不再移动浮球，再次打开时按浮球位置在画布内展开。
- 修复提示词节点中键滚动，滚动条按节点几何贴边显示。
- 删除渠道时停止引用该渠道的活动任务，已提交到上游的付费请求不会自动重发。

**桌面封装**

- NSIS 安装器与卸载器显式使用项目图标，安装包在资源管理器中显示轻画图标。
- 发布包继续执行签名校验、Ed25519 验签和真机启动门禁。
