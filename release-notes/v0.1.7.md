## 0.1.7 · 存储 V2 与单一资源根（2026-10-24）

> 本版从 `0.1.6` 升级到 `0.1.7`，重新构建并使用原更新私钥签名 Windows NSIS 安装包。

**存储 V2**

- 权威库升级为 `manifest.sqlite + media/`：项目、节点、电商任务与结果进入 SQLite，
  图片、视频和音频以普通文件保存，节点和电商结果只保留 `assetHash` 引用。
- 正式迁移 470 个素材、2,156,388,895 字节、354 张缩略图、123 张预览图和 8 个 KV 记录；
  原 V1 数据目录完整保留，可回滚。
- 旧 16 位 `assetHash` 继续作为业务引用；新增完整 SHA-1 校验，迁移发现 21 个旧冒烟素材，
  已显式标记保留，没有覆盖或丢弃。

**资源目录与迁移**

- 存储设置收敛为单一“资源目录”，移除独立的生成文件目录和新素材自动镜像。
- 支持打开目录、切换已有 V1 / V2 目录、只读预检、正式迁移并切换、重建缩略图和预览图。
- 迁移期间自动暂停共享存储写入，完成或失败后解除维护模式；未通过全量回读不会写完成清单。
- 桌面壳和开发脚本会根据完整 `manifest.json` 自动选择 V1 / V2 后端。

**验证**

- shared-store Rust 25/25、Tauri 41/41、Vitest 3,086 passed / 1 skipped。
- 设置页 1440×900 与 1024×700 无横向溢出；画布 60 个节点和可见缩略图全部加载成功。
- NSIS 安装包使用原 `qinghua-updater.key` 签名，产物启动门禁与 Ed25519 验签通过。
