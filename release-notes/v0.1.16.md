## 0.1.16 · Agent 可信性、过程显示与拆分收口（2026-11-05）

> 本版从 `0.1.15` 升级到 `0.1.16`，继续使用原更新私钥签名。

**Agent 可信性**

- 画布动作在承诺“我可以做”之前必须先查能力；没有对应工具时直接说明当前做不到。
- “已改好 / 已完成 / 已生成”等完成声明必须有本回合对应工具的成功结果；只读画布、只改参数或
  `problems` 非空都不能冒充成功，`applyPlan` 建工作流也不能冒充真正生成。
- 改名、改标题、节点名称查询不再误匹配到 `updateNode`；当前没有改名工具时会明确说明，不再假装改好。
- 同一回复里先写“改好了”、后面才带工具调用的正文会被撤下；被门禁拒绝的流式草稿会立即清理。

**Agent 稳定性与界面**

- 确认执行后重新确保聊天路由，修复图片已成功却误报“渠道已删除”的问题。
- 工作流落图自检失败会立即回滚并回读，修复“界面说没建成、画布却留下节点和连线”的双真相。
- 修复 Agent 过程文字重复、工具展开区重复，以及“一直显示理解后突然铺满结果”的流式展示问题。

**代码拆分**

- 能力词表、完成证据和补查状态收进 `agentCanvasClaimGuard.ts`；`agentLoop.ts` 只保留接线。
- Agent 工具、会话存储、会话中枢、回合主链和面板样式继续按领域拆分，并加入行数与禁止回流的结构护栏。
