## 0.1.1 · 漫剧工作台 + 电商长图 + 素材标签 + 桌面通知（2026-10-12）

0.1.0（2026-10-05 发布）之后的工作里，**用户看得见**的部分都在这一版。

**新增**

- **漫剧工作台（全流程）**：小说 / 剧本 → 自动拆集 → 用模型拆分镜 → 铺到画布逐镜出图 →
  逐镜视频 → 角色与场景资产库（定妆图 / 基准图，可直接回喂给生成）→ 时间轴预览这一集 →
  **导出合成包**（素材清单 + 一条可直接执行的 FFmpeg 命令 + SRT 字幕，时间轴同源）。
  资产支持手工合并，以及「同义归并查重」（模型只给候选与理由，逐条由你确认，否掉的以后不再问）。
- **电商专业工作区**：详情页长图（1920 宽等比拼合 + 段落编排 + 导出 PNG）、
  左栏「一句话 → 待确认方案」、分镜扩写（先看方案再出图）、历史方案、为您推荐；上传位支持拖放。
- **素材库**：给素材打标签并按标签筛选；修掉"长提示词的失败卡片被瀑布流从中间切断"。
- **桌面与设置**：接上**系统通知**（壳插件，取代页内提示单一通道）；项目页可按
  画布 / 电商 / 漫剧筛选；全局设置左导航 11 个栏目配线性图标；渠道配置页与工作区同底色；
  渠道图标可从网站抓取（桌面壳内可用）。

**数据与迁移**

- 数据目录仍是 `轻画\{app,data}` 布局（0.1.0 起），**覆盖安装与自动更新都不碰数据**；
- 本版**没有破坏性数据结构迁移**；老项目读回时按新模型补齐字段（对白独立文本层等）。

**已知缺口（如实记，不装成已完成）**

- 漫剧的配音（TTS）/ 口型 / BGM、多视角 turnaround 属研究稿里"刻意推迟"的项，本版未做；
- 电商长图的像素级编辑（裁剪 / 抠图 / 局部重绘 / 延展 / 超清 / 文字）未做 ——
  要么需要渠道能力，要么等价于"去画布里改这一张"；
- `Wan 3.0` 与 `Gemini Omni Flash 1.1` 两个视频模型**没有内置参数表**：没有可验证的来源，
  不让猜的档位进代码，面板退回"按渠道上报能力渲染"。
