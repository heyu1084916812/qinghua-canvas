## 0.1.12 · Agent 长任务可靠性、会话隔离与工具契约升级（2026-11-02）

> 本版从 `0.1.11` 升级到 `0.1.12`，继续使用原更新私钥签名。

**Agent 生命周期**

- 关闭 Agent 面板不再卸载运行宿主；思考、停止、队列、确认卡、草稿和附件处理继续存活，重新展开仍保留壳层动画。
- 用户消息在聊天路由准备和第一次模型请求前按目标会话落库；后台处理一个会话时不会读取当前界面另一个会话的历史。
- 路由失败、能力探测失败和用户中断都会正确结束 Job，不留下虚假的 `planning` 状态，也不丢失已发送消息。
- per-image、sticky 图片 / 视频模型和工具上下文按会话隔离；队列附件在同一事务内冻结并消费，连续排队不会重复携带。

**工具与恢复**

- 同一批多个工具调用改为唯一、有序配对；确认、取消、中断和参数错误都不会再产生重复或悬空 tool result。
- 自动模式只放行 `runNode / runFrom`；删除、改节点、写记忆仍必须人工批准。
- 画布写入在工具账本完成前等待持久化屏障；flush 失败保留待写批次，后续可重试，结果未知时进入待核对而不是自动重放。
- `readResult` 优先读取持久 RunRecord 的最近失败状态，旧产物不会伪装成本次成功；MIME 使用真实节点元数据，最小尺寸缩放保持宽高比。

**边界与验证**

- 本版保证关闭 Agent 面板不丢运行态；离开整个画布路由仍会卸载宿主，跨路由后台执行需要后续独立 AgentHost。
- `AgentPanel.tsx` 与 `tools.ts` 仍偏大，后续继续按发送、工具执行、确认和视图拆分，不在本版做高风险大重构。
- 全量 Vitest **3807 passed / 1 skipped**；`npm run check` 全绿；G735 明暗各 **35/35**；G769 明暗各 **38/39**，唯一失败为既有过程行 fixture（期待 1 行、实际 2 行），与本次 Agent 链路无关。
