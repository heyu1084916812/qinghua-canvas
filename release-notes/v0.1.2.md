## 0.1.2 · 键盘微移与改尺寸 + 两条数据缺陷修复（2026-10-12）

0.1.1 之后的一批：把「无障碍」这条从 9 月底挂到现在的缺口**收口**，
并在动手过程中**量出两条既有真缺陷**（都不是这一版新加的功能带来的）。

**新增**

- **键盘也能挪节点、改尺寸**（§4.5「拖拽替代」/ §6.20）：
  `Alt + 方向键` 微移 **1px**（按住 `Shift` 一次 10px）；
  `Ctrl / ⌘ + Alt + 方向键` 改尺寸，同样两档步长。
  尺寸走的是**与拖右下角完全相同**的那套规则（最小尺寸、图片按原始比例锁、
  循环节点高度归内容、批量的网格比例），到边界**不会往撤销栈里塞空操作**；
  只对**顶层节点**生效（分组 / 批量里的子节点由容器排布，不动它们）。
  帮助面板的快捷键表已补上这两条。

**修复**

- **按方向键会偷偷把节点挪 5px**：React Flow 自带那套键盘层在"有选中节点"时
  每次把节点挪 **5px**（`Shift` 时 20px），而且**不看 `Alt` / `Ctrl`** ——
  于是按一下普通方向键（本意是"切到下一个节点"）节点就被挪 5px，
  `Alt + →` 实测走 **6px**（我们的 1 + 它的 5），改尺寸时位置也被带走 5px。
  现在关掉它自带那层，键盘全部走本项目自己那一套（实测 **0 / 1 / 0**）。
- **撤销之后刷新，那次撤销会白做**：撤销 / 重做落库时把补丁里的**旧值**又写了回去 ——
  内存已经退回、库里还停在改动后。因为移动命令每帧同时写 x 和 y，症状是"只错一轴"，
  肉眼几乎看不出来。现在三处（内存 / 库 / 画面）一致。

**已知缺口（如实记，沿用 0.1.1 那三条）**

- 漫剧的配音（TTS）/ 口型 / BGM、多视角 turnaround 属研究稿里"刻意推迟"的项，本版未做；
- 电商长图的像素级编辑（裁剪 / 抠图 / 局部重绘 / 延展 / 超清 / 文字）未做；
- `Wan 3.0` 与 `Gemini Omni Flash 1.1` 两个视频模型没有内置参数表（没有可验证的来源，不猜）。
