## 0.1.3 · 修掉「删了又立刻撤销会真丢」（2026-10-12）

**修复**

- **删掉节点后 800ms 内按 `Ctrl + Z` 撤销：库里那一行会被删掉** —— 内存里节点好好的、画面也在，
  **刷新一次就真没了**。根因是落库器把一批待写操作**先全部写、再全部删**：删了又撤销这一串会攒成
  「写回那一行 + 删除那次删除」，**删在后面** ⇒ 数据丢失。现在合并待写清单时让
  **后到的操作把先前的相反操作抵消掉**（后写覆盖先写，与落库器自己的语义一致）。
- 这条在界面上**完全看不出来**（内存与画面都是对的），所以单测判据特意落在**库里那一行**：
  删除 → 撤销 → 落盘 → 库里必须仍有它。

**已知缺口**：与 0.1.2 相同（漫剧的配音 / 口型 / BGM 与多视角、电商像素级编辑、
两个视频模型没有内置参数表 —— 都不猜）。
