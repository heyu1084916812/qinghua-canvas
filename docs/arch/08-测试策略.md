## 8. 测试策略 · 🧩 部分实现

| 层 | 测试类型 | 位置 | 依赖 |
| --- | --- | --- | --- |
| `domain` | 单元测试 + 属性测试 | `src/domain/**/*.test.ts` | 无 |
| `state` | 集成测试（内存平台） | `src/state/**/*.test.ts` | `createMemoryPlatform()` |
| `features` | 集成测试 | `src/features/**/*.test.ts` | store + 内存平台 |
| `ui` `panels` | 组件测试 | `*.test.tsx` | Testing Library |
| 全链路 | E2E | `e2e/*.spec.ts` | Playwright + mock 渠道 |
| 视觉 | 截图回归 | `.playwright-verify/` | Playwright，对 `/_preview` 批量截图 |

`domain` 与 `features` 的测试不需要浏览器，这是把纯逻辑从组件里抽出来的直接收益。
