**样式约定**（三条，由 lint 强制）

1. 样式文件与组件同目录，使用 CSS Modules，类名作用域天然隔离。
2. 组件之间不通过选择器互相覆盖；跨组件的视觉差异走 `props` 或变体类名。
3. 颜色、圆角、字号、间距、阴影、动效时长只从 `ui/tokens.css` 与 `ui/motion.ts` 取值，字面量颜色出现在组件样式里即视为违规。
