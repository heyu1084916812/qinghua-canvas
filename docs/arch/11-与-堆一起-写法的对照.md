## 11. 与"堆一起"写法的对照 · ✅ 已实现

| 症状 | 机制 |
| --- | --- |
| 2542 行的页面组件 | 页面容器只做接线，节点内容在 `canvas/nodes/<type>/` |
| 6 类节点渲染混排 | 注册表分发，每类一个目录 |
| 标题菜单端口各写一遍 | `NodeFrame` 写一次 |
| 样式被旧规则覆盖 | 令牌集中在 `ui/tokens.css`，组件样式与组件同目录 |
| 撤销保存各写各的 | 命令层统一产出 `inverse` 与 `persist` |
| 改一个 bug 碰出另一个 bug | 依赖单向 + 节点目录互不引用，由工具链强制 |
| 逻辑无法脱离 UI 测试 | 纯逻辑下沉 `domain`，测试不需要浏览器 |
| 打磨 UI 要跑通业务流程才能看到效果 | `/_preview` 陈列室一次看全状态，批量截图做视觉回归 |
| 想换配色要全局搜索替换 | 令牌单点 + `[data-theme]`，换肤不碰组件 |
| Agent 改画布后无法撤销 | Agent 只能走命令总线，一次动作一个事务 |
| 加 Agent 要重写网络层 | `NetworkPort.stream` 签名在 M0 落地 |
