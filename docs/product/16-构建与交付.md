## 16. 构建与交付

### 16.1 产物与运行方式

| 产物 | 说明 |
| --- | --- |
| `dist/` | `npm run build` 产出的静态文件，可直接托管或本地打开 |
| `npm run dev` | Vite 开发服务，默认 `http://127.0.0.1:1420`，带 API proxy |
| `npm run preview` | 本地预览生产构建 |
| `RELEASE_NOTES.md` | 版本说明：新增、修复、已知问题、数据迁移与回退说明 |

轻量边界：构建产物是纯静态文件，无服务端、无 WASM 运行时、无原生模块。产物只依赖浏览器能力。

### 16.2 依赖清单

| 类别 | 依赖 |
| --- | --- |
| 运行时 | React、TypeScript、Vite、Zustand、Dexie |
| 开发时 | ESLint、dependency-cruiser、Vitest、Playwright |
| 不引入 | UI 组件库、画布框架（React Flow 等）、CSS-in-JS 运行时、状态机库 |

画布自研的原因：分组、批量的容器 + 坐标嵌套变换 + 集合展开语义，是现成画布框架的弱项，深度定制的代价高于自研。

### 16.3 交付验收

- 断网、缺少渠道、没有项目时仍能正常进入首页
- shared-store 不可用、数据库损坏、磁盘配额不足三类故障显示人类可读的恢复页面
- 页面标题、favicon 与文档统一为「轻画」
- 生产构建无控制台错误、无开发日志、无测试密钥、无 sourcemap 外泄
- 首屏体积符合 §13 的体积指标

### 16.4 版本与迁移

- 版本遵循 SemVer；shared-store 的 `schemaVersion` 与应用版本分别管理
- 更新静态产物即完成升级，浏览器内数据由迁移流程自动处理
- 数据发生不可逆迁移时先提示用户导出备份

### 16.5 后续形态

桌面壳（Tauri 2）留作后续版本。接入时替换的是 `platform` 层的实现，本产品文档第 1–15 章的行为、数据与验收标准保持不变，仅 §2.3 运行形态、§11.4 网络边界、§12.1 存储布局三节需要追加桌面分支。
