## 10. 状态机与微交互

### 10.1 通用状态

每个异步操作从以下状态集合中选择：

`idle → validating → queued → running → retrying → succeeded | partial | failed | canceled`

| 状态 | 表现 |
| --- | --- |
| `queued` | 已进入本地调度队列，尚未发出请求 |
| `running` | 请求已发出；按钮文本改为「取消」，防止重复提交 |
| `retrying` | 展示 `第 1/2 次重试` 与下一次重试原因；用户可立即取消 |
| `succeeded` | 反馈 1.5 秒后弱化，结果与日志保持 |
| `partial` | 部分成功；成功项与失败项分别展示 |
| `failed` | 错误持续显示直到修复、重试或关闭 |
| `canceled` | 保留输入和已成功的部分结果，允许重新运行 |

### 10.2 关键微交互矩阵

| 场景 | 触发 | 规则 | 即时反馈（≤ 100ms） | 过程 / 结果反馈 | 恢复路径 |
| --- | --- | --- | --- | --- | --- |
| 自动保存 | 任一可持久化变更 | 800ms 防抖；离开页面前强制 flush | 项目名旁出现小圆点 | `保存中 → 已保存`，1.5s 后弱化 | 失败时常驻「保存失败」+ 重试 |
| 单节点生成 | 生成按钮 / `R` | 冻结快照；防重复提交 | 按钮按下并变为「取消」 | 节点显示排队、运行、重试；完成后产物落到承载节点 | 取消 / 重试 / 查看日志 |
| 批量生成 | 批量节点生成 | 逐项产生任务；成功项不重复 | 显示 `0/N` | 确定进度 `x/N`；可后台运行 | 仅重试失败项 |
| 建立连线 | 拖端点或空白松手菜单 | 只接受合法输入；落点吸附 | 目标节点高亮；拖线期间创作面板隐藏 | 成功线条落位；非法时红色并说明原因 | `Esc` 取消，撤销可恢复 |
| 拖入容器 | 拖动节点 | 命中区延迟 150ms 后进入预览 | 容器底色与插入位置显形 | 松手后归属更新；显示「已移入…」 | 撤销 / 拖出 / 菜单移动 |
| 删除 | Delete / 菜单 | 普通节点直接删并提供撤销；含内容容器先确认 | 删除对象淡出 ≤ 120ms | 底部撤销条保留 6 秒 | 撤销；容器默认解散不删内容 |
| 导入项目 | 打开文件 / 拖入文件 | 先校验格式、版本、容量和模型引用 | 文件名与解析状态 | 显示迁移、冲突和完成摘要 | 失败不产生半成品项目 |
| 渠道验证 | 验证地址 | 使用脱敏凭据，10s 超时 | 按钮内联 spinner | 显示延迟、协议、TLS/CORS/HTTP 分类 | 重试 / 编辑地址 / 展开技术详情 |
| 渠道探测 | 验证协议 | 逐个试打候选协议（已剔除离线协议），命中即写回并落库 | 状态行「正在探测协议…」 | 协议下拉自动切到命中的协议，左栏短标签同步 | 全失败给最后一条原因；地址为空直接拒绝 |
| 复制提示词 | 点击日志文本 | 写剪贴板 | 文本区域短暂高亮 | 行内「已复制」1.5s | 失败提示系统剪贴板权限 |

### 10.3 反馈强度与时间

| 等级 | 事件 | 表现 |
| --- | --- | --- |
| 低 | hover、聚焦、选中、吸附 | 控件自身状态变化 |
| 中 | 保存、复制、导入完成、生成成功 | 行内状态或非阻塞撤销条，1.5–6 秒 |
| 高 | 删除含内容容器、覆盖节点、清空日志 | 确认对话框，明确对象数量与后果 |
| 错误 | 保存失败、请求失败、素材损坏 | 靠近问题源持续显示，含原因、下一步和技术详情 |

- 预计耗时 `< 300ms` 不显示 spinner；`300ms–5s` 使用内联 spinner；`> 5s` 显示进度或阶段；`> 30s` 允许后台运行并在完成时通知
- 反馈同时使用图标与文本
- 所有动画可中断，用户的新操作拥有优先级

### 10.4 微交互验收

以下 8 项全部通过才算 10/10：触发可发现、触发状态可见、规则可预测、100ms 内反馈、反馈强度匹配、重复使用不过度打扰、模式清晰、首次使用无需说明。M2 验收时对「生成、保存、连线、删除、渠道验证」逐项评分，任一项低于 9/10 时先补齐再进入 M3。
