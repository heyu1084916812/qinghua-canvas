## 5. 页面一：首页与项目页

### 5.1 布局结构 · ✅ 已实现（2026-09-27）

```
┌──────────────┬──────────────────────────────────────────────┐
│  左侧功能栏  │  右侧工作区                                  │
│  （可展开）  │                                              │
│              │  项目                                        │
│  [首页]      │  ┌────────┐ ┌────────┐ ┌────────┐           │
│  [项目]      │  │项目卡片│ │项目卡片│ │  + 新建 │           │
│  [画布]      │  └────────┘ └────────┘ └────────┘           │
│  [技能库]    │                                              │
│  [我的素材]  │  模板库                                      │
│  [渠道配置]  │  ┌────────┐ ┌────────┐ ┌────────┐           │
│  最近项目    │  │ 空白   │ │ 文生图 │ │ 图生图 │           │
└──────────────┴──────────────────────────────────────────────┘
```

- 首页保留品牌（猫画动态图标）、欢迎与两个入口：**新建项目**（直接建空白项目并进画布）
  与**我的项目**（去 `/projects`，想从模板开始时走这条）。
  项目列表迁到一级「项目」页 —— 首页是「进门第一眼」，不是第二个项目页。
- 品牌文字标是用户提供的 **QINGHUA 字形**（用户 2026-09-29 第 13 轮引入，第 14 轮补全为
  完整字形，含 Q 斜尾与 A 四角星），配色走 `currentColor` 随主题色（`--text-1`）自动切换，
  定高 28px 等比缩放（约 172px 宽）。字形本身没有可读文本，`<h1>` 以 `aria-label="轻画"` 保留页名。
- 项目页内容相对**右侧工作区**居中，不是相对整个浏览器窗口居中；侧栏展开或收起时，只在新的工作区宽度内重新居中。
- 项目工作区**页内边距 32px**；标题「项目」为 **24px / 32px / 500**（色值 `#F5F4EF`，用户 2026-09-28 按 Lovart 定稿），
  与项目卡片名称 **14px / 500** 形成清晰的两级层次。
- 项目网格首张是「＋ 新建项目」，其后是项目卡片；卡片固定 **303 × 180**（用户 2026-09-28 最终口径，不是只保持比例），
  栅格按可用宽度自动换行并整体居中；**不为了凑列数缩小卡片**，也不产生横向溢出。
- 字体说明：Lovart 实测主西文字体是商业字体 **GT Standard**，中文回退 **Noto Sans SC**。
  本项目不内置 GT Standard 字体文件；当前使用 `Segoe UI Variable / Microsoft YaHei UI / PingFang SC` 回退栈。
  若用户提供有授权的 GT Standard，可只替换西文字体令牌；未授权前不以“复刻”为名打包。
- `项目 / 画布 / 技能库 / 我的素材 / 渠道配置` 共用同一个工作区宽度与页面内边距。

### 5.2 顶栏 · ⛔ 已退役

首页不再有自己的顶栏。品牌与一级导航统一由应用壳左侧功能栏承担；渠道配置从侧栏进入。

### 5.3 项目卡片 · ✅ 已实现

- 顶部：**项目封面**，固定 **303 × 180**（Lovart 口径，用户 2026-09-28；尺寸不可随窗口缩放）。
  - 封面 = **最后一次出现在画布中的图片**（用户 2026-10-06 定的口径，对账 #289 / #299；
    原口径是"最近一次生成出的最后一张图"，漏了**上传 / 导入**进来的图）。
    两个候选、一个判据（谁的时间更晚谁当封面，打平取生成的）：
    **生成产物**取 `runRecords.createdAt`（不是节点上的 `assetHash` —— 那个只有「当前这张」，
    没有「什么时候生成的」）；**上传 / 导入**取 `projects.extra.cover` 那一笔
    （由 `importAssetFile` —— 所有导入路径的唯一咽喉 —— 在导入时顺手记下）。
    规则本身是纯函数（`domain/project/cover.ts`），**不在**列表页实时扫 `assets` 表：
    那表每行带全分辨率字节，按项目查一次就等于"打开首页把几百 MB 拉进内存"。
    **已知边界**：把 A 项目导入的图复制粘贴到 B 项目，B 的封面不会因此更新。
  - **平铺铺满、不拉伸**：`object-fit: cover`（等比放大到铺满，多余裁掉）。
    刻意不是 `fill`（那才会变形），也不是 `contain`（那会留边、不满足「占满」）。
  - 视频产物用 `<video preload="metadata">` 停在第 0 帧当静态封面，**不自动播放**
    （一排卡片同时解码十几个视频是性能事故）。
  - **没有产物时**（新项目 / 只连线没跑过）回落成 24px 网格占位，不显示破图。
- 卡片为**无边框无圆角**的透明容器（列布局，间距 `4px`），封面即卡片视觉主体；
  封面下方第一行是项目名称，**14px / 500**；第二行是相对更新日期 + `N 个节点`（14px / 400，二级文字色），
  每行独立截断。卡片上**不再显示「画布 / 漫画」工作台标签**。
- hover / focus：整卡浮出 `var(--bg-hover)` 底，**右下角**出现 `⋯` 菜单（重命名 / 复制 / 导出 / 删除）；
  按钮 **28 × 28px**，深色圆角方块（圆角约 `9px`）、无描边，默认隐藏、菜单向上展开。
- 网格列宽固定 **303px**，间距 20px，按可用宽度自动换行并整体居中；窗口变窄时减少每行列数，但不缩小卡片
- 标题「项目」右侧有**选择模式**入口：进入后每张卡右上角出现勾选框，底部浮栏显示「全选 / 清除 / 取消」；选中后「删除」走二次确认并批量移除
- **滚动发生在页面内部**（2026-10-06，对账 #287 / #298）：此前滚动是 `[data-app-workspace]`
  （那张**圆角卡**）自己做的 ⇒ 滚动条画在卡片最右沿，上下两端正好落在圆角上（用户："头部都漏出来了"）。
  现在页面定高、由内容列（`.main`）自己滚，并给内容列一条**透明右边框 16px**
  把滚动条推进卡片内部（`padding` 推不动滚动条 —— 它画在 padding 之外，只有 border 能；两边同宽以保持内容居中）。
  素材页同款。

### 5.4 模板库 · ✅ 已实现

| 模板 | 预置内容 |
| --- | --- |
| 空白项目 | 空画布 |
| 文生图 | 提示词节点 → 图片生成节点 |
| 图生图 | 底图生成 → 图生图（两端同为 image 模式，走 /v1/images/edits，M6-12） |
| 图生视频 | 图片节点 → 视频生成节点 |
| 批量出图 | 提示词 → 图片生成（数量 4）→ 对比节点 |
| 批量套图 | 批量节点（空容器，等用户拖入外部素材）→ 生成节点 |

- 「图生图」是代码里已有而本表此前漏记的一条，现补齐（M6-22 对账）。
- 「批量出图」末端的对比节点**消费的是承载节点**：4 张结果落在 4 个并列承载节点上，
  对比节点按 §6.10「取前 2 张」从上游承载节点取图
  （`upstreamImagesOf(expandResults)`，M6-22）——否则这条主流程「连上了却只有 A 没有 B」。
- 预置节点的坐标给产物留了落位（批量出图的对比节点在 x=1040），
  避免跑完后新承载节点压在预置节点上。

点击模板立即创建项目并进入画布。卡片 hover 浮现灰色底。

### 5.5 排序与搜索 · ✅ 已实现

排序：最近编辑（默认）/ 创建时间 / 名称 A-Z。搜索按项目名模糊匹配。

### 5.6 空状态 · ✅ 已实现

无项目时显示一行次文本「还没有项目，从下方模板开始，或新建空白项目」。

### 5.7 项目导入与导出 · ✅ 已实现

| 能力 | 规则 |
| --- | --- |
| 导出 | 导出为 `.flow.json`，含项目、节点与连线；素材可勾选「内嵌素材」或「仅结构」 |
| 导入 | 导入为新项目，重名自动加后缀 |
| 密钥 | 导出默认不含 API Key；需连同渠道分享时显式勾选并二次确认 |
| 冲突 | 引用的模型不存在时标记节点为「模型缺失」，由用户重选 |
