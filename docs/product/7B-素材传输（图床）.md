## 7B. 页面五：素材传输（图床）· 2026-10-03 新增

一级导航第 7 项「素材传输」（`/hosting`），**独立成页**而不是塞进渠道配置：图床与「某个站
怎么连」无关，同一张图可能要给 Agnes、也可能要给别家；写进渠道就会出现两张渠道卡各配一遍
同一个图床（对账清单 #114）。

页面只有一张卡：

| 元素 | 规则 |
| --- | --- |
| 服务 | 分段选择：**关闭（默认）** / `tmpfiles.org`。关闭时**不上传任何素材** |
| 保留时长 | 仅当选了图床时出现：1 小时 / 6 小时 / **24 小时（默认）** / 48 小时 —— `tmpfiles.org` 只认这四个值（3600 / 21600 / 86400 / 172800 秒） |
| 测试上传 | 用一张 32×32 的真 PNG 走一遍真实链路，成功时把**直链**显示出来（`https://tmpfiles.org/dl/…`），失败时如实报错 |

两条实现口径：

1. **默认关闭**：参考类生成不依赖图床 —— Agnes 实测**收 Data URI（Base64）**
   （`mode:keyframes` + `image:[data:…×2]` → 200），所以没配图床时走内联 Base64；
   配了才先上传、改用公网直链（请求体更小，链接也能给别处复用）。
2. **图床挂了不拖死参考功能**：上传失败一律回落内联 Base64（`referenceUrls` 里 catch 掉）。

> **选型依据（2026-10-03 在应用 origin 的浏览器里逐个真传）**：freeimage.host / catbox /
> uguu / qu.ax / envs.sh / file.io / 0x0.st 全是 `Failed to fetch`（没 CORS 或本网络到不了），
> pixeldrain 要 API key，litterbox 回 `412 No file!` —— **只有 `tmpfiles.org` 能用**。
> 它返回的是**页面地址**，直链必须换成 `/dl/<id>/<name>`，否则上游抓到的是一张 HTML 页。
