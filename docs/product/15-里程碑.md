## 15. 里程碑

| 里程碑 | 范围 | 交付标准 |
| --- | --- | --- |
| M0 架构与骨架 | 目录骨架、依赖检查、Web 平台实现、状态切片、节点注册表、令牌与陈列室、流式端口与 Agent 接口预留、提示词节点纵向切片 | 新增一个节点类型只改 3 个文件；依赖检查、类型检查、单测全绿 |
| M1 项目与画布 | 项目管理页（卡片网格 + 模板库 + 导入导出）、画布视口、提示词节点、IndexedDB 落库 | 能建项目、加节点、拖拽缩放 |
| M2 生成链路 | 生成节点（空态 / 有内容、面板三部分、产物落位）、日志面板、设置页、单次生成跑通 | 能从 0 配渠道并出图 |
| M3 编排能力 | 连线与数据传递、对比节点、分组节点、批量节点（四种场景）、框选与对齐、整理节点 | 能跑通批量套图与批量文生图 |
| M4 能力完善 | ~~画板节点（绘制 + 一键运行）~~（2026-09-30 下线）、LLM 优化与翻译、撤销重做、性能优化 | 可日常使用 |
| 后续：第二个工作台 | 在不修改画布的前提下，新增一个同级工作台（漫画剧） | 共享 `assets` / 渠道 / 日志 / 任务运行时；工作台之间零代码互引；首页按 `workbench` 字段分发跳转；新增包通过路由级 lazy 不进入首页 bundle |
| M5 第二工作台骨架 | 漫画剧工作台以并列方式落地（M0-9 插槽兑现）：`WorkbenchId` 加 `comic`、私有 store 与命令、`/comic/:id` 路由级 lazy、首页新建时可选工作台、卡片带工作台标识 | 能新建漫画剧项目并进入其工作台页面；画布工作台零代码改动；depcruise 跨工作台隔离规则生效；首页 bundle 不含 comic 实现 |
| M6 漫画剧形态 | **M6-1 共享边界收口**（画布专用文件如实归位 + `no-shared-to-workbench` 规则）✅；**M6-2 数据模型 v2**（阅读方向 + 角色卡 + 切割树版式 + 三层格 + 读回迁移 + 最小可见 UI）✅；**M6-3 页版式编辑器**（切割树树编辑 + 阅读序号印章 + RTL/LTR 联动 + 刷新读回）✅；**M6-4 格编辑 + 对白层**（右栏三段式：画面描述 / 镜头语言 / 角色多选；左栏对白贴纸层：可拖 + 四类型可切）✅；**M6-5 格 → 生成**（生成块 + 格内底图 + **执行引擎真解耦路径 B**：落位适配器注入，comic 提供第二个实现）✅；**M6-6 一话总览 + 翻页预览**（缩略网格（M6-9 起含生成底图与页码角标）+ 全屏只读阅读器 + 翻页手感随阅读方向）✅；**M6-7 双页跨页阅读**（单页/双页切换 + 封面单页与末页落单 + 孤页按「先读侧」对齐 + 跨页步进 + 翻页动效随方向镜像）✅；**M6-8 整套导出**（一话 / 项目 → ZIP 图片包：单页每页一张 PNG、跨页两页并作一张且命名即页区间；导出与阅读共用同一套封面 / 分组口径）✅；**M6-9 缩略底图与页码角标**（总览缩略叠生成底图 + 右下叙事页码角标，未生成不假装）✅；**M6-10 拖拽翻页**（按住拖动跟手，过阈值翻页、不够回弹，边界阻尼、纵向不接管，与按钮/键盘同源）✅；**M6-11 导出页码**（可选「页码」开关，默认不打；页码落在页下方的页脚带里、**不压画面**，跨页时两页各一条带、帖外侧，每话内从 1 起且与总览角标同源）✅；**M6-12 渠道消费 `inputs`**（图生图 / 角色参考图生效：带图像输入走图生图端点、不带则零回归；画布新增「图生图」模板、上游生成节点产物自动作参考图；不支持时如实报错不静默降级）✅；**M6-13 角色卡参考图上传**（角色卡内可直接上传 / 移除参考图；上传的图与生成产物共用同一素材库、「id 即内容哈希」故同图重传幂等；至此「传参考图 → 勾角色 → 生成带上它」在界面上从头到尾可走通）✅；**M6-14 对白贴纸尺寸手柄与拖尾巴**（补齐 M6-4 的两条直接操作：右下角手柄改尺寸、尾巴本身可拖改指向；气泡与尾巴一体平移/缩放，故只有拖尾巴能改指向）✅；**M6-15 生成留痕与版本回退**（重生成不再丢上一版：留痕住格内 `runs`、只增不减、版本号由历史自身推出、回退本身追加为新版本；失败如实留痕但不可回退）✅ | 分镜可排版、格可编辑、对白可拖、**格能生成出图**；重生成不丢对白；一话可总览（**一眼看出哪几页画完了**）、可翻页阅读、**可双页跨页阅读**、**可拖拽翻页**；**可整话 / 整项目导出为图片包**（**可选打页码**）；**可给角色卡传参考图并用于生成**；**对白可改尺寸 / 可拖尾巴指向**；**重生成不丢历史版本、可回退**；canvas 冒烟零回归 |
