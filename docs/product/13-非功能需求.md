## 13. 非功能需求

| 类别 | 指标 |
| --- | --- |
| 性能 | 单画布 300 节点 / 500 连线下平移缩放 ≥ 50fps；视口外节点不挂载 DOM |
| 体积 | 生产构建首屏 JS ≤ 300KB gzip；不引入 UI 组件库与画布框架 |
| 容量 | 单素材 ≤ 50MB；提供清理未引用素材入口；容量预警接入 `navigator.storage.estimate()` |
| 兼容 | Chrome / Edge 120+ / WebView2；依赖本机 shared-store、WebCrypto、CSS Modules 与 Container Queries 等稳定能力 |
| 稳定性 | 自动保存防抖 800ms；异常关闭后可恢复 |
| 安全 | API Key 经 WebCrypto `AES-GCM` 加密后存本地，业务代码不接触明文；导出默认不含密钥 |
| 可访问性 | WCAG 2.2 AA；键盘可完成核心工作流；所有拖拽提供可见替代操作 |
