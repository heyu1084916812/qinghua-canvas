### 2.2 页面流转

```
应用壳（左侧功能栏 + 右侧工作区）
  ├─ 首页 /              欢迎页；新建空白画布后自动切到「画布」导航
  ├─ 项目 /projects      项目卡片网格；内容按右侧工作区居中
  ├─ 画布 /canvas/:id    当前正在编辑的画布；无项目时打开空白画布
  ├─ 电商 /ecommerce/:id 表单出图（产品图 + 参数）→ 结果区可拼长图并导出；产物就是这个项目的画布节点
  ├─ 漫剧 /storyboard/:id 剧本 → 分集 → 分镜 → 资产库（定妆图 / 基准图）→ 铺到画布出图 → 逐镜视频
  │                    → 导出分镜表 / 合成包（FFmpeg 命令 + SRT）+ 时间轴预览这一集
  ├─ 技能库 /skills      卡片浏览 → 点击卡片编辑；含功能预设词
  ├─ 我的素材 /assets    手动收藏素材库；角色库 / 场景库后期补齐
  ├─ 全局设置（浮层，侧栏底部）  渠道、协议、模型与模型路由 / 素材传输（两个子菜单，§2.1）
  └─ 所有项目            树状导航：置顶 / 文件夹 / 未归档画布·电商·漫剧

画布工作区内部：
  ├─ 右上角「日志」── 打开现有日志面板（浮层，功能与内容不变）
  ├─ 小地图附近显示缩放百分比
  ├─ 双击素材 ────── 打开灯箱（浮层）
  └─ 底部水平工具条居中保留在画布内（新建 / 排列整理 / 撤销重做 / 导入素材 / 重置视图）
```

日志与灯箱均为画布内浮层，不产生路由跳转。一级页面统一由应用壳承载左侧功能栏；页面内容只占右侧工作区。

**应用壳与左侧功能栏**

- 侧栏与右侧工作区**在布局上并排**：**展开态**（= 钉住 **或** 悬停）把工作区挤窄，收起态 64px。
  ⚠️ 这条口径变过两次，第三次别再改回去 —— **2026-10-08 用户改回来了**：
  「左边这个悬停是长出来的，不是往右推出来的，我要的是展开按钮展开的那种效果」。
- **两种展开，只差"松手后收不收"**（用户 2026-10-08 口径）：
  - **悬停** = 临时展开：铺到 240px 并**把工作区推出去**（与点按钮一模一样），移开鼠标（220ms）后收回；
  - **钉住**（点标题栏那枚按钮）= 常驻展开：移开鼠标也留着。
  两者外观与动画**完全相同** ⇒ "是不是浮层"不再是它们的区别（2026-10-06 那版"悬停 = 浮层、不推挤"
  是为压住用户报的「左边的菜单栏变成闪动了」而定的，**但那次闪的真根因不是推挤本身**，见下条）。
  实现：占位宽度（`--sidebar-w`）与侧栏自己的可见宽度**同源**（同一个"是否展开"），
  壳层多一个 `.railSlot` 空盒负责占位。
- **⚠️ `.railSlot` 的宽度必须由 `width` 驱动，绝不能写进 `flex` 简写**：`flex: 0 0 <宽>` 算出的是
  `flex-basis`，而 `flex-basis` **优先于 `width`** ⇒ `transition: width` 动的是一个被忽略的值，
  占位**一帧内跳到位**而侧栏还在 140ms 里慢慢滑 —— 一边瞬移一边滑动，看起来就是"闪"
  （2026-10-06 那次误判的根因，2026-10-08 #377 修掉：`flex: 0 0 auto` + `width`，两者同一条过渡）。
- **图标列钉在中轴上**：收起态是「图标中心 = 侧栏中轴 32px」，**展开态必须落在同一处**
  （左距 = `--rail-icon-left`，两个状态共用）。不共用的话折叠瞬间整列图标会横跳
  （实测 nav/＋/设置/skills +2px、Logo −2px），而"收起态用 `justify-content: center`"更糟 ——
  "居中"算的是**实时宽度**，折叠动画刚起步（宽度还是 240）时图标会被甩到 ~113px 再滑回来。
- **悬停即展开**（用户 2026-10-06 改的口径，取代旧的"点击展开"）：侧栏默认**收起**、宽度 `64px` 只显示图标；
  鼠标**进入侧栏**即自动展开到 `240px`，移开自动收回。两个延迟刻意不对称 ——
  **进 `100ms`、出 `220ms`**（"短进长出"）：0 延迟会让鼠标横穿侧栏时一闪一合，
  比慢一点难看得多；退出延迟长一点，允许手抖或短暂移开再回来。
- 顶部折叠按钮的语义随之改变：它不再是"开 / 合"，而是**常驻开关** ——
  按下 = 常驻展开（移开鼠标也留着），再按 = 取消（交回给悬停）。**常驻态落盘、跨重启记住**
  （键 `flow:sidebar-pinned`）；**悬停是临时态、不落盘**。
  原始口径见用户原话：「悬停的时候他就能展开，折叠按钮只是控制他是否常驻折叠或者展开」。
  收起态下按钮不可见（不抢 Logo 的位置），用 `:focus-visible` 保证键盘用户可达。
- 展开动画走**横向滑动**（`transform` / 宽度过渡），右侧工作区同步自适应缩小。
  ⚠️ 旧口径「不记忆上次状态，刷新回到收起态」**已作废**：现在记的是"用户锁没锁"，
  不是"上一次偶然是不是开着" —— 没锁过仍然是收起态。
- 侧栏内距 **16px 12px**（纵向 / 横向）；品牌位、新建按钮、导航项、折叠按钮统一 **40px** 高，
  收起态与展开态的命中区不跳变。
- 侧栏分**四组**（用户 2026-09-28；2026-10-19 更新）：品牌位 + 折叠按钮 / 新建项目 / 功能菜单 / 所有项目树，
  组与组之间留 **20px**；主题切换仍钉在侧栏底部。
- **展开时不跳动**（用户 2026-09-28）：Logo 与导航图标的横向位置在展开前后完全不变，
  只有容器与文字**向右扩展**；折叠按钮在展开态移到导航容器右边缘对齐（图标 `20×20`）。
  收起态 Logo 与折叠按钮同格、同圆心（按钮 `34×34`），悬停互换，不产生位移。
- 导航图标与文字的**明暗一致**（用户 2026-09-28）：深色下统一 `#efefef`，
  选中态与未选中态**同色**，只靠底色 + 字重区分；分组标题走二级文字色。
- 导航项顺序固定为：`首页 / 项目 / 画布 / 电商 / 漫剧 / 技能库 / 灵感库 / 我的素材`；
  「渠道配置 / 素材传输」仍在全局设置浮层（见 §2.1），下方是 `所有项目` 树。
- **侧栏底部三段**（自下而上）：`主题切换` → `检查更新` → **`全局设置`**（2026-10-06 新增，#259）。
  顺序是用户定的：全局设置在「检查更新」**上方**。
- 收起态隐藏文字与「所有项目」树，只保留各功能图标；图标与展开后的文字都必须完整可见，不截断、不互相挤压。
- **折叠 / 展开不闪**（2026-10-06，对账 #281 / #294）：宽度有 180ms 过渡，而文字原先跟着 `open`
  **瞬间挂载 / 卸载** ⇒ 展开那一帧 8 个标签已经就位、侧栏还只有 64px，每个都被裁出半截字
  （收起时反过来：文字先消失、宽度再慢慢收）。现在文字与「所有项目」树**常驻 DOM**，
  只按节奏淡入淡出 —— 收起先淡出、淡完再 `visibility: hidden`（`visibility` 的过渡延迟 = 淡出时长），
  展开延迟 60ms 淡入、与宽度过渡同时收尾；收起态那几个"只剩图标"的按钮（新建 / 全局设置 / 检查更新）
  一律 `justify-content: flex-start` + 固定内距 —— 居中会让图标被**仍占位的标签**挤走
  （实测图标 x 从 23 掉到 **-10**，被推出侧栏）。两种状态下图标落点完全一致。
- **忙态不许"变灰"**（2026-10-07，对账 #323）：「检查更新」在查更新的那 ~2 秒里是 `disabled`，
  早期用 `color: var(--text-3)` 表达不可用 ⇒ 图标**从灰跳回深**（实测 `t=42ms` 灰 → `t=2081ms` 深），
  读起来就是"闪"。现在**两态同色**（一律 `--sidebar-nav`），"在查"改由**动画 + 文案**表达
  （箭头转圈 + 标签变「正在检查…」），`prefers-reduced-motion` 下停转、只留文案。
  口径：**侧栏行的状态变化不靠颜色** —— 颜色只用于选中 / 悬停这类"位置感"反馈。
- **全局设置是模态浮层**（2026-10-06，对账 #259 / #296）：结构是**左侧一列导航 + 右侧内容**
  （渠道配置 / 素材传输 / 存储三栏；`data-global-settings-tab` 是栏目切换锚点）。
  右栏自带 `overflow-y: auto` —— 这是「素材传输无法下拉」那个 bug 的修法：
  那一栏是照"整页工作区"写的（自己没有 overflow，靠外层壳滚），放进浮层后被裁掉、滚不动。
- **全局设置右栏固定标题区**（2026-10-25，对账 #744）：顶部固定显示当前栏目大标题和一行简介，
  下方正文独立滚动。右栏只允许三档文字：`24px / 600` 栏目标题、`14px / 500` 分组标题与控件标签、
  `13px / 400` 正文与说明。子面板的重复长导语删除，保留会影响决策的边界提示、错误和空态。
- **默认参数分三类**（2026-10-25，对账 #744）：图片 / 视频 / 对话各自解析对应 `image / video / chat`
  的默认配方；图片与视频保留比例、画质、张数，对话只保存模型。
- **侧栏底部常驻「主题切换」**（用户 2026-09-27 拍板）：明 / 暗两档切换，收起态也保留图标位。
  它是全局设置，放在全局壳层上；画布内不再有主题按钮。
- **选中态是「隐性」的**（用户 2026-09-27 二轮）：只靠**底色 + 字重**表达，
  **不描边**。上一版带 1px 内描边，读起来像输入框而不是导航项 ——
  导航的选中应该是「位置感」，不是控件的边界感。
- **品牌位是猫画那个动态图标**（用户 2026-09-27）：收起态与开合按钮**同一格**——
  平时显示图标，鼠标悬停（或键盘焦点进入）时图标隐去、按钮显现，移开后图标回来。
  图标与按钮**同尺寸、同圆心**，切换时不会有大小或位置跳变。
- 所有一级页面共用**同一个右侧工作区宽度与内边距**，切换页面不横向跳动。
- **收起态图标居中**（用户 2026-10-06 第 11 批补：「注意：图标不居中了」）：64px 侧栏里
  Logo / 新建＋ / 五个导航项 / 底部三件的图标**中心都落在中轴（32px）**。
  做法是把**内联文字标签压成零宽**（`[data-sidebar-label]`）—— 标签仍常驻 DOM、仍按宽度节奏淡出
  （不闪），但不参与宽度计算，于是 `justify-content: center` 居中的就是图标本身。
  展开态仍是"与 Logo 左对齐"（两态之间图标移动 ≤4px，肉眼不可辨）。
- **自绘标题栏高度 = 33px**（用户 2026-10-06 第 11 批第 3 条「缩三分之一」，A 方案）：
  旧的「标题栏 + 上方留白 = 侧栏折叠宽度 64」**作废**（现在 33 + 15 = 48，与 64 不再相关）；
  条内从左到右是 **折叠键 → 应用 → 编辑**，窗口三键贴右上角（`margin-left: auto`，不再用 `space-between`）；
  菜单按钮仍 28px 高、字号不变。这条由 `scripts/check-shell-geometry.mjs` 看住
  （判据改成"≈旧口径的三分之二 ±1px"，防止有人改回 49 或随手写别的数）。

- 置顶项目单列在最上方，不在文件夹和未归档里重复；置顶文件夹排在文件夹区最前。
- 每个项目行显示工作台类型、置顶按钮和更多菜单；菜单包含重命名、移入文件夹、复制路径、
  在资源管理器中打开、上传到 OSS、关闭当前画布、置顶和删除。
- 文件夹菜单包含重命名、置顶、新建三种项目、展开 / 收起、移出全部项目、复制路径、
  在资源管理器中打开、上传文件夹到 OSS 和删除。删除文件夹只把项目移到未归档，不删项目。
- 侧栏重命名使用居中弹窗；项目页卡片原有的内联重命名保持不变。
- 项目 / 文件夹变更通过 `projectEvents` 通知侧栏立即刷新，不要求用户切页或重开应用。
- “复制路径 / 资源管理器”使用当前素材文件夹的绝对路径；没有素材文件夹时回落到桌面数据目录。
  “上传到 OSS”复用全局设置里的素材传输配置，没有配置时明确失败，不假装上传成功。

**画布页内部的日志与缩放**

- 原顶部悬浮栏（项目标签、日志、渠道设置、主题、缩放读数）整体去除。
- 日志按钮移到画布工作区**右上角**，打开的是现有日志面板，记录内容、缩略图、复制提示词、发送到画布等能力一字不变。
- 缩放百分比移到小地图附近，只显示数值；不额外做加减号与适配按钮。

**技能库与渠道配置的职责边界**

- 技能库是一级页面：第一层是卡片浏览（搜索、筛选、新建、导入），点击卡片进入第二层编辑。
- 技能库同时承载**功能预设词**，不再放在渠道配置页。
- 渠道配置页只负责渠道、协议、模型拉取、模型选择与模型路由。
- 技能分两层来源且**不同表**：
  - **内置技能**：随应用提供，只读默认版本；用户可“复制为我的技能”进行修改，也可恢复默认。
  - **用户技能**：用户新建、导入或从内置复制而来，可编辑、删除、导入导出。
- 功能节点后续可直接依赖内置技能正文；因此内置与用户技能必须在数据层分开，不能靠同一张表的标记位区分。

### 2.3 运行形态

轻画 v1.0 以 **Web 应用**形态交付：一个纯前端站点，构建产物是静态文件，用任意本地静态服务或 `npm run preview` 打开即用。

- **本地共享存储服务**：`shared-store` 在 `127.0.0.1:18765` 提供唯一权威库；调试壳、release 壳和浏览器共用同一份数据。服务只监听本机，不联网。
- **IndexedDB 降为旧版迁移来源**：新业务数据不再按 origin 写入 IndexedDB。旧库只作一次性迁移或回滚备份，避免 `127.0.0.1` / `tauri.localhost` / 浏览器 profile 各存一份。
- **API 访问经 Vite dev proxy**（开发态）或**用户自行配置的可信中转站**；请求直连中转站时受同源策略约束，开发态统一走 proxy，详见 §11.4。
- **凭据存于本机 shared-store**：由 WebCrypto `AES-GCM` 加密，密钥由本机随机盐派生，仅用于本机，不上传任何位置。
- 除模型调用、拉取模型与协议验证外，项目编辑、搜索、导入导出与日志浏览均离线可用。
- 节点执行日志写入 `runRecords`；`tasks` 仅保留为兼容旧数据的任务表。

### 2.4 会话与启动

| 项 | 规则 |
| --- | --- |
| 启动 | 打开地址后直接渲染首页；首次进入无项目时显示空状态与模板库 |
| 多标签页 | 同一浏览器多标签打开时，以最后写入为准；检测到外部写入时提示「项目已在其他标签页修改」并提供刷新 |
| 视口适配 | 设计基准 `1440 × 900`；最小支持 `1024 × 720`，更窄窗口保证可读与可恢复 |
| 关闭 | 离开页面前强制 flush 未落盘事务（`beforeunload` + `visibilitychange` 双保险） |
| 外部链接 | API 文档等外链在新标签页打开 |
| 异常恢复 | 启动时读取中断标记，检测到未正常退出时提供「恢复上次编辑 / 打开已保存版本」，见 §12.2 |
| 浏览器要求 | Chrome / Edge 120+；`npm run dev` 会同时启动 shared-store，桌面壳会自动启动它。服务不可用时**明确报错，不静默退回 IndexedDB** |
| 桌面形态 | 已交付 Tauri 2 壳：随包里带 shared-store、Canvas MCP stdio、FFmpeg 与 updater 签名清单；Windows 10/11 x64 是当前发布范围。历史 IndexedDB 只作迁移来源，不再作为新业务权威库 |
