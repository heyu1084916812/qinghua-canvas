## 3. 视觉系统

本章是颜色、字体、圆角、间距与动效的唯一来源，其余章节只引用语义名，不复写具体值。

### 3.1 色彩

> **2026-09-27 用户给定色值定稿**（下表已是新值）。层级关系（三层，低 → 高）：
> **画布工作区 `--bg-canvas` → 一级菜单 `--bg-app` → 卡面 `--bg-surface`**。
> 亮色下工作区纯白、菜单 `#F5F5F5`，菜单**比工作区暗一档**；
> **深色下反过来**：工作区 `#161616`、菜单 `#1A1A1A`，菜单**比工作区亮一档**。
> 两套主题「谁比谁亮」方向相反，故**不能共用一个相对关系**，各自给值。
>
> 由此带来一条易错点：页面是壳右侧**工作区**里的插槽，底色必须填 `--bg-canvas`，
> **不是 `--bg-app`**（后者现在是菜单色）。旧配色下两者接近看不出，新配色下会染成菜单色。

| 角色 | Token | 值 |
| --- | --- | --- |
| 画布底（工作区） | `--bg-canvas` | `#FFFFFF` |
| 主背景（一级菜单） | `--bg-app` | `#F5F5F5` |
| 高层浮面 | `--bg-surface` | `#FFFFFF` |
| 次级底 | `--bg-subtle` | `#F5F5F5` |
| 悬停胶囊 | `--bg-hover` | `#E2E2E2` |
| 描边 | `--stroke` | `#E2E2E2` |
| 网格 | `--grid-line` | `#ECECEF` |
| 主文字 | `--text-1` | `#171717` |
| 次文字 | `--text-2` | `#737373` |
| 弱文字 | `--text-3` | `#9A9A9A` |
| 主操作填充 | `--accent` | `#171717` |
| 主操作文字 | `--accent-text` | `#FFFFFF` |
| 焦点 / 选中 | `--stroke-focus` | `#171717` |
| 成功 | `--success` | `#2F7D5A` |
| 警告 | `--warn` | `#9A6424` |
| 错误 | `--danger` | `#B4473A` |
| 键盘焦点环 | `--focus-ring` | `#5B67D6` |

**深色档取值**（`[data-theme='dark']`，同表结构）：工作区 `#161616` / 菜单 `#1A1A1A` /
卡面 `#222222` / 次级底 `#1F1F1F` / 悬停 `#333333` / 描边 `#3A3A3A`；
文字 `#EFEFEF` / `#A2A2A2` / `#767676`；主操作填充 `#EFEFEF`（文字 `#161616`）。

`--accent` 的语义收窄为「实体主按钮填充」。层级强调一律用填充，描边只用于表达焦点与选中。高饱和色只来自用户素材。
强调色保持单一八档色板，不另列「黑色系」。节点中原本的黑底按钮（主操作、选中态、加号、
数字选中格、融合按钮等）必须统一引用 `--node-contrast-*`，而该组令牌直接来源于
`--accent` / `--accent-text`；因此换强调色时按钮同步变色，hover 由强调色与表面色混合。
色块按当前主题显示，切换主题自动改用配对色值。

**主题档位：只有明 / 暗两档**（用户 2026-09-19 第 9 条：「只要两个主题色，去掉跟随系统」）。主题按钮是**两档互切**（浅 ⇄ 深），每次点击必然产生可见的外观变化。

> 此前是「明 / 暗 / 跟随系统」三档轮转。去掉第三档的理由：色彩表本就只定义了两套取值，
> 第三档不产生新外观，却让「点一下到底变成了什么」多一层心算。
> **迁移口径**：系统偏好只在**首次读取**（没有已存选择、或旧值非法）时用来定初始档位；
> 旧版本存过的 `'system'` 现在不是合法档位，一律按系统偏好落成一个**具体**档位——
> 这样老用户外观不变，第三档也不会从旧数据里复活。两档之后**不再监听系统偏好变化**。

### 3.2 字体与圆角

- 字体：`"Segoe UI Variable", "Microsoft YaHei UI", "PingFang SC", sans-serif`；数字与任务耗时启用 `tabular-nums`。
- 字号（**2026-09-27 整体上调一档**：原 13/12/11 在 1080p 下比参考站细碎）：正文 **14px** / 行高 1.6；节点标题 14px / 500；二级标签 **13px**；面板标题 **15px** / 600；参数 chip **12px** / 600。**各级相对关系不变**（面板标题 > 正文 > 标签 > chip）。
- 字体**全局设在 `ui/base.css`**（`html, body` 设 `font-family` + 表单控件 `font: inherit`）。两条缺一不可：表单控件（button / input / select / textarea / optgroup / option）**默认不继承字体**，只设 body 的话它们仍是 UA 字体的 Arial，界面混着两套字形。历史教训见对账清单「七」同名条目。
- **字距 `0.04em`（2026-10-05 用户第 4 批：「这些文字字间距都很小，显示的很挤」）**：字体栈第一个是 `Segoe UI Variable`，中文走系统回退 —— 汉字之间几乎贴在一起，一屏密排的中文读起来就是「挤」；参考产品那套更松。只做**正向**微调（基准 16px ≈ 0.64px），不做负字距。⚠️ **表单控件要单独补一句 `letter-spacing: inherit`**：Chrome 下 `font: inherit` **带不出字距**，按钮 / 输入框会回到 `normal` —— 少这一句就是「正文松了、按钮和输入框还挤」（实测过：body 0.64px、参数 chip `normal`）。
- 圆角：节点与面板 14px；按钮、输入框、参数 chip 与参数选择面板 10px；胶囊 999px。**节点内容区填满型内层容器**（生成节点素材容器等，内缩仅外框 1px 描边者）用同心圆角 `14px − 1px = 13px`（`--radius-node-inner`），否则角上出现两条不同弧。
- 间距：基础 4px，常用序列 4 / 8 / 12 / 16 / 24 / 32。
- 交互目标最小 40px，核心操作 44px。

**项目级画布底色**除六档预设外，还提供「自定义颜色」控件：左侧色块打开原生取色器，右侧是固定 `#`
前缀的 HEX 输入框与「应用」按钮。支持手填 `RGB` / `RRGGBB`；非法值保留当前画布色并显示
“请输入 3 位或 6 位十六进制色值”，成功应用后显示“正在使用 #……”。自定义色存
`projects.extra.canvasStyle.customColor`，显示时覆盖预设色调并随项目导出。网格线按自定义底色亮度
自动与黑或白混合，保证任意底色下仍可辨认。点击任一预设色调即清除自定义色。

**节点底色**使用同款颜色控件，存在 `projects.extra.canvasStyle.nodeColor`。设置后同时覆盖
`--node-fill` 与 `--node-inset`，所有节点外框和内容井统一换色；为空时跟随主题默认
（浅色 `#ffffff` / 深色 `#222222`）。可点“恢复主题默认”随时清除，自定义值同样随项目保存和导出。

### 3.3 层级表现

| 场景 | 表现 |
| --- | --- |
| 画布工作区浮层（创作参数面板、节点、节点菜单、画布右键菜单、工具条、小地图、缩放控件、连线删除控件、拖动中的节点） | 无投影，使用 `1px solid var(--stroke)` 描边与背景明度区分层次 |
| 大对话框（首页新建、日志面板、灯箱、设置页模型选择器） | 保留投影 |
| 参数选择面板（ParamPicker） | 无投影，`1px solid var(--stroke)` 描边，圆角 10px，宽度 `max-content`，`min-width 96px`，`max-width 300px`（2026-10-03 由 280 放宽：比例网格三列 72px + 内距 12 已经装不下） |
| 节点选中 | `outline: 2px solid var(--stroke-focus)` |
| 节点内部 | **统一 `--node-fill`**：浅色为 `#ffffff`，深色为 `#222222`（2026-10-25 修订：浅色节点内部统一纯白）。提示词 / 生成 / 对比 / 融合 / 循环共享同一个节点面；图片舞台与输入井用 `--node-inset`（浅色同为 `#ffffff`），控件用 `--node-control`，边框使用 `--node-border` / `--node-border-inner`。批量节点同用这套表层，内部不描边、与节点同色；分组继续使用六档容器背景。循环节点的轨道与按钮统一为**透明底 + 描边**，其中“循环 / 并发”由同一滑块在两者间平移、按钮本身不描边；主操作与选中态统一使用 `--node-contrast-*`：浅色黑底白字，深色反转为浅底深字。参数排为批次 / 起始计数 / 次数，运行按钮独占下一排；四组控件内容整体居中，纯文字与文字+数字都保持上下、左右等距。图片状态区分无图 / 正常输出 / 起始越界，不再把越界误写成“没有上游图片”。提示词区不再套外层框，编辑框撑满；计数按钮为圆角矩形，插入 chip 为 6px 圆角、透明底、正文色文字、1px 描边、不带 ×，chip 内字号与正文同为 11px / 400，内边距 `0 3px`、左右间距 `1px` 并垂直居中；添加提示词加号跟随 `--node-contrast-*`；右上删除 × 与左上编号同款实际 18px 实心圆，两圆顶边对齐且距节点左右边缘均为 4px。节点之间的区别靠内部内容与控件层级表达，不靠随机底色差 |
| 参数胶囊 hover | 浮现 `var(--bg-hover)` 底、圆角 999px、无描边 |
| 全局滚动条 | 统一 4px、无箭头、半透明拇指；滚动时显示，停止滚动 1 秒后轨道与拇指一起透明。由 `ui/scrollActivity.ts` 在 `html` 上维护 `data-scroll-active`，禁止组件另写标准 `scrollbar-width` / `scrollbar-color` 绕过全局规则 |
| 全局左侧功能栏 | 与右侧工作区同级；收起 / 展开由用户触发；配色走既有令牌 |

### 3.4 动效

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| hover 胶囊浮现 | 120ms | `ease-out` |
| 参数选择面板展开 | 140ms | `cubic-bezier(.2,.8,.2,1)` |
| 右键菜单出现 | 120ms | `ease-out` |
| 灯箱打开 | 180ms | `cubic-bezier(.2,.8,.2,1)` |
| 连线端点淡入 | 100ms | `ease-out` |
| 节点选中描边 | 0ms | 即时 |
| 画布缩放 / 平移 | 走 `transform` + GPU 合成 | 无过渡 |

生成落位是产品的签名时刻：承载节点先稳定出现（N 张即 N 个并列节点），产物从来源方向依次落位。所有动画可中断，用户的新操作拥有最高优先级。遵循 `prefers-reduced-motion`，减少动态时关闭空间位移、保留状态反馈。（~~结果组创建~~ 已于 2026-09-17 下线，见 §6.9。）
