## 1. 产品定位

### 1.1 定位

面向 AI 创作者的生成工作流编排工作台。用无限画布把「提示词 → 生成 → 对比挑选 → 再生成」固化为可视化节点流程，支持单节点调试、批量处理与局部融合，全部数据留在本机。

### 1.2 目标用户

| 用户 | 诉求 | 关键场景 |
| --- | --- | --- |
| AI 绘画 / 视频创作者 | 批量出图、反复对比挑图 | 一次跑 4 张，对比节点割线挑最优 |
| 提示词工程师 | 管理提示词变体与参数组合 | LLM 优化提示词 + 多模型横向对比 |
| 独立开发者 / 小团队 | 自用工具、成本可控、数据私有 | 自建中转渠道、本地存档、导入导出工作流 |

### 1.3 核心场景

1. **批量出图**：提示词节点 → 图片生成节点（数量 4）→ 右侧 4 个并列承载节点 → 对比节点割线挑图
2. **图生视频**：已有素材节点 → 视频生成节点（继承上游图作为首帧）
3. **提示词优化**：简短描述 → 提示词节点接 LLM → 优化成完整提示词 → 生成节点
4. **批量套图**：批量节点放 2 张图（猫、狗）+ 外部 1 张衣服图 → 生成节点写「图一穿上图二的衣服」→ 一次得到 2 张结果
5. **批量文生图**：批量节点放 3 条提示词 → 点生成 → 右边出 3 张图
6. **局部融合**：从图片素材提取选区，经模型多轮修改后由融合节点回填原图

### 1.4 产品原则

| 原则 | 约定 |
| --- | --- |
| 无边框 | 层级由留白、底色变化与悬停态表达，界面以无描边容器为主 |
| 白色基调 | 画布与面板以纯白 / 近白为底，图片与视频是画面中唯一的高饱和元素 |
| 克制动效 | 动效服务于「让人理解发生了什么」，单段时长 ≤ 200ms |
| 按需显形 | 参数控件、缩略图删除按钮与小眼睛默认弱化，在悬停、键盘聚焦或触控选中时浮现 |
| 悬停胶囊 | 悬停胶囊底框统一为浅灰底、无描边、圆角 999px |
| 实体主按钮 | 主操作（生成 / 应用 / 发送到画布 / 保存配置）使用实色填充表达权重 |
| 本地优先 | 业务数据落在本机 shared-store 权威库，无账号、无云端、无远程业务服务端 |
| 内容为主角 | UI 在未激活时保持隐形（端点、参数框、手柄、操作按钮默认隐藏） |

### 1.5 版本范围

| 能力域 | v1.0 范围 | 后续版本承载 |
| --- | --- | --- |
| 账号与协作 | 项目默认只存在本机 | 账号体系、多人协作、云端同步 |
| 模型供应 | 用户自行配置兼容渠道与 API Key | 内置额度与计费 |
| 流程能力 | 确定性有向无环工作流 | 条件分支、循环节点、定时任务、远程队列 |
| 素材编辑 | 提取选区 + 融合节点做局部回填 | 图层、蒙版、滤镜系统 |
| 终端适配 | 桌面浏览器窗口，设计基准 `1440 × 900`，最小 `1024 × 720` | 移动端编辑、桌面壳发行 |
| 数据治理 | 素材去重、容量预警、视口持久化 | 定时快照、素材回收区、版本树 |

### 1.6 成功指标

| 指标 | 目标 | 验证方式 |
| --- | --- | --- |
| 首次出图完成率 | 新用户在 10 分钟内完成「新增渠道 → 验证 → 选择模型 → 生成 1 张图」≥ 80% | 可用性测试，5 名以上目标用户 |
| 工作流复用效率 | 已有项目再次打开后，3 次操作内可重新运行任一生成节点 | 可用性测试 |
| 数据可靠性 | 1000 次模拟写入与异常退出中，已确认保存的数据零丢失 | 自动化恢复测试 |
| 启动性能 | 本地静态服务下首屏可交互 P95 ≤ 2 秒 | Lighthouse 与本地计时 |
| 画布性能 | 300 节点 / 500 连线、1440×900 下平移缩放 P95 ≥ 50fps | 性能基准脚本 |
| 核心可访问性 | 键盘可完成建项目、建节点、连线替代、生成、撤销、删除与保存 | 键盘与读屏验收 |

### 1.7 性能预算

- 画布平移、缩放、节点拖动与批量吸附只更新 React 本地状态，拖动过程中不写 shared-store，不为每一帧重排全部子节点。
- 指针移动处理使用 `requestAnimationFrame` 合帧，同一帧内只计算一次世界坐标、连线与小地图。
- 拖动 / 排序松手后只提交一次持久化事务，自动保存采用 800ms 防抖。
- **例外：素材（`assets` 表）插队立即落库，不等防抖**。节点拿到 `assetHash` 的那一刻就要按它把图画出来，而素材字节只在本机 shared-store 里有一份；跟着防抖走会出现「上传完先空白一会儿」（连传时更长）。素材是内容寻址的幂等写入，提前写没有副作用；其余数据仍走防抖，否则拖节点每帧都要落库。
- 普通指针反馈在 100ms 内出现；300ms 以上的网络或模型操作显示进行中状态。
- 批量节点内部只重排受影响的同层子节点，节点数量增长时布局计算保持线性复杂度。
